The converter's input, $V_{\mathrm{BUS}}$, is an external input: the board's USB-PD
front end presents \SIrange{8.5}{13}{\volt} whenever it has negotiated a
contract this converter can run from (\cref{sec:pd-classes}; the front end also
admits a \SI{5}{\volt} contract, which \cref{sec:hv-uvlo,sec:hv-inhibit} keep
this converter out of), with
\SI{9}{\volt} the lower contract voltage. Everything else in this section (the
output setpoint, every component value, and the two bracketing operating points used
throughout) is derived below.

\subsection{Preliminaries}\label{sec:hv-prelim}

Three items are free parameters or self-contained checks, each depending only on the
$V_{\mathrm{BUS}}$ window above and the LM5155 characteristics of \cref{sec:lm5155}.

\subsubsection{Switching frequency and RT}\label{sec:hv-fsw}

For a target of \SI{150}{\kilo\hertz} (an aesthetic-driven choice, accepted as
input), the RT equation of \cref{sec:lm5155} gives
\begin{align*}
  R_T &= \frac{2.21\times10^{10}}{f_{RT}} - 955
       = \frac{2.21\times10^{10}}{1.5\times10^{5}} - 955
       = \SI{146.4}{\kilo\ohm}.
\end{align*}
The nearest standard value is $R209 = \SI{147}{\kilo\ohm}$, giving
\begin{align*}
  f_{RT} &= \frac{2.21\times10^{10}}{147\,000 + 955} = \SI{149.4}{\kilo\hertz}
\end{align*}
($-0.4\,\%$ from target; period $T = \SI{6.695}{\micro\second}$). Specification:
$R209 = \SI{147}{\kilo\ohm}$; all subsequent arithmetic uses
\SI{149.4}{\kilo\hertz}.

The DA2032-AL is characterized only at a \SI{100}{\kilo\hertz} test point
(\cref{sec:da2032}); operating it at \SI{149.4}{\kilo\hertz} is an extrapolation.
For a DCM flyback the inductance and saturation figures translate directly, but
core loss at the higher frequency is uncharacterized; it is carried below
(\cref{sec:hv-op}) as an explicit allowance, and this extrapolation is listed as an
assumption in the summary.

\subsubsection{Input UVLO}\label{sec:hv-uvlo}

UVLO must keep the converter disabled below its rated \SI{8.5}{\volt} input
minimum, with margin against the LM5155's own threshold tolerance and against a
sagging \SI{9}{\volt} USB-PD contract dipping toward \SI{8.55}{\volt} at its
$-5\,\%$ limit: an enable point sitting right at \SI{8.5}{\volt} would risk
enabling into an input the converter is not specified to run from. A target of
roughly \SI{8.1}{\volt}, a few hundred millivolts below both, gives that margin
without pushing the enable point needlessly low.

The UVLO/SYNC pin's thresholds (\SI{1.5}{\volt} rising / \SI{1.45}{\volt} falling
typical, \cref{sec:lm5155}) are set by an external divider from $V_{\mathrm{BUS}}$
to ground: $V_{\mathrm{on}} = V_{th,\mathrm{on}}(R_{207}+R_{208})/R_{208}$,
requiring a ratio $(R_{207}+R_{208})/R_{208} \approx 8.1/1.5 = 5.4$ to hit the
target above.

R208, the lower leg, is a free parameter within that ratio: tens of kilohms is
standard practice for a sense divider on this class of controller, low enough that
its own quiescent draw off $V_{\mathrm{BUS}}$ stays negligible, high enough that the
\SI{5}{\micro\ampere} hysteresis current this pin sources while enabled
(\cref{sec:lm5155}) still produces a meaningful hysteresis voltage across
$R_{207}\!\parallel\!R_{208}$ rather than being swamped by pin leakage.
\SI{32.4}{\kilo\ohm} is adopted, giving
\begin{align*}
  R_{207} &= R_{208}\left(\frac{8.1}{1.5} - 1\right)
          = 32.4 \times 4.4 = \SI{142.6}{\kilo\ohm}
          \;\rightarrow\; \SI{143}{\kilo\ohm}.
\end{align*}

Verifying against both thresholds:
\begin{align*}
  V_{\mathrm{on}} &= 1.5 \times \frac{143 + 32.4}{32.4} = 1.5 \times 5.414
                  = \SI{8.12}{\volt},\\
  V_{\mathrm{off}} &= \left(1.45 - I_{\mathrm{hys}}
      (R_{207}\!\parallel\!R_{208})\right)\times 5.414
    = (1.45 - 5\,\si{\micro\ampere}\times 26.4\,\si{\kilo\ohm}) \times 5.414
    = \SI{7.14}{\volt},
\end{align*}
with $V_{\mathrm{off}}$ spanning \SIrange{6.99}{7.28}{\volt} over the
\SIrange{4}{6}{\micro\ampere} hysteresis-current range: about \SI{1}{\volt} of
hysteresis. The rising threshold lands \SI{0.38}{\volt} below the \SI{8.5}{\volt}
minimum operating input, meeting the target margin, so the converter is guaranteed
enabled across the specified window and disabled before the input falls into
duty-cycle-starved territory.

The same pin carries the separate, lower EN comparator
($\approx$\SI{0.52}{\volt} rising). Through this divider that corresponds to
$V_{\mathrm{BUS}} = 0.52 \times 5.414 = \SI{2.8}{\volt}$: on any monotonic input
ramp EN is satisfied \SI{5.3}{\volt} before UVLO releases, so one divider serves
both comparators and no separate EN network is needed.

\subsubsection{Display inhibit}\label{sec:hv-inhibit}

UVLO answers whether the input voltage is one this converter can run from. It
cannot answer whether the negotiated supply can carry what the converter will
draw, because those are different questions with different answers on the same
input voltage: \cref{sec:pd-sequence} starts the board on a contract sized for
the low-voltage rails alone, and that contract may sit at \SI{9}{\volt}, well
above the \SI{8.12}{\volt} at which this divider releases. Started there, the
converter would light the tubes into a supply short of what they need.

The distinction is available only to the MCU, which reads the contract, so the
inhibit is an MCU output and the requirement on it is that its unasserted state
be the inhibited one. Q202, an N-channel MOSFET across R208, holds the UVLO/SYNC
pin at ground when on, which is below the \SI{1.45}{\volt} falling threshold by
the whole of it. Its gate is pulled to the 3.3~V rail through R215, so the shunt
conducts as soon as that rail exists and the converter is held off through
reset, through boot, and through any interval in which the MCU stops driving the
pin. Releasing the display is a deliberate act: the MCU pulls the gate down.

The requirement on Q202 is slight, and stating it as a resistance rather than as
a threshold is what makes it satisfiable by an ordinary part. It carries
$V_{\mathrm{BUS}}/R_{207} = \SI{13}{\volt}/\SI{143}{\kilo\ohm} =
\SI{91}{\micro\ampere}$, and the pin must end up below the \SI{1.45}{\volt}
falling threshold, so the channel need only be
\begin{align*}
  R_{DSon} &\leq \frac{\SI{1.45}{\volt}}{\SI{91}{\micro\ampere}}
    = \SI{16}{\kilo\ohm}
\end{align*}
at \SI{3.3}{\volt} of gate drive. That is four orders of magnitude above what
any small-signal MOSFET conducts when fully on, so the selection question is not
on-resistance but whether the device conducts at all at that drive: the
requirement is a gate-source threshold low enough to be fully overdriven at
\SI{3.3}{\volt}, not a part characterized for on-resistance there. Specifying
$V_{GS(th)} \leq \SI{2}{\volt}$ maximum leaves \SI{1.3}{\volt} of overdrive and
resolves it, and is a parameter every MOSFET datasheet tabulates.

It stands off the divider's own node voltage when open, \SI{2.4}{\volt} at the
top of the input window, giving $V_{DS}\geq\SI{3}{\volt}$ with the
\SI{20}{\percent} derating: no part in this class comes near that limit.
R215 $= \SI{100}{\kilo\ohm}$ pulls the gate up against a leakage-only load and
against an MCU pin that sinks it.

The arrangement leaves UVLO doing exactly what \cref{sec:hv-uvlo} derives, since
the shunt is either fully on or fully off and never shifts the threshold. It
also means the hysteresis current the pin sources while enabled flows through
the divider unchanged whenever the converter is running, the shunt being open in
that state.

\subsubsection{Controller housekeeping (BIAS, VCC, PGOOD)}\label{sec:hv-house}

\paragraph{BIAS.}\label{sec:hv-house-bias}
BIAS ties to $V_{\mathrm{BUS}}$ (\SIrange{8.5}{13}{\volt}), inside the
\SIrange{3.5}{45}{\volt} recommended range with a $3.5\times$ margin to the
\SI{50}{\volt} absolute maximum. TI's own reference boost design (List of
Materials, \ds{lm5155.pdf}{26}) decouples this pin with $C_{\mathrm{BIAS}} =
\SI{0.01}{\micro\farad}$, but does so behind a series $R_{\mathrm{BIAS}}$
filter resistor between the supply and the pin, a resistor this design
omits, tying BIAS directly to $V_{\mathrm{BUS}}$. Without that series
element, BIAS is electrically the same node as $V_{\mathrm{BUS}}$, which
already carries substantial bulk capacitance at this point (C202, C203,
\cref{sec:hv-caps}): C211's role reduces to a local high-frequency bypass
right at the pin rather than bulk energy storage, the same role the
reference design's smaller value fills. There is accordingly no functional
reason to depart from the reference value. C211 $= \SI{0.01}{\micro\farad}$
(10~nF, X7R, matching the reference part class).

\paragraph{VCC regulator capacitor.}\label{sec:hv-house-vcc}
The VCC regulator's output capacitor must sit inside the datasheet's
\SIrange{1}{4.7}{\micro\farad} recommendation (\ds{lm5155.pdf}{14}). A value
above the \SI{1}{\micro\farad} floor leaves margin against the DC-bias
derating typical of small ceramic capacitors at the \SI{6.85}{\volt} VCC rail,
without needing the full \SI{4.7}{\micro\farad} the range allows. C201
$= \SI{2.2}{\micro\farad}$ (a standard ceramic value) is adopted.

\paragraph{PGOOD pull-up.}\label{sec:hv-house-pgood}
PGOOD is open-drain (\cref{sec:lm5155}) and needs an external pull-up, bounded
on both sides: the datasheet's $\ge\SI{10}{\kilo\ohm}$ recommendation keeps the
open-drain sink current small, while the pull-up must still charge the pin's
parasitic capacitance well inside the \SI{25}{\micro\second} deglitch window
already built into the pin's assert condition (\cref{sec:lm5155}); even a
generous \SI{20}{\pico\farad} of stray capacitance gives
$\tau=RC\approx\SI{2}{\nano\second}$ at \SI{100}{\kilo\ohm}, five orders of
magnitude below that window. R206 $= \SI{100}{\kilo\ohm}$ is adopted,
pulling to the +3V3 logic rail. Against the pin's own ratings
(\cref{sec:lm5155}): \SI{3.3}{\volt} is far under the \SI{18}{\volt} absolute
maximum (and under $V_{\mathrm{BIAS}}+\SI{0.3}{\volt}$, relevant because of the
pin's internal diode to BIAS, \ds{lm5155.pdf}{22}); asserted-low sink current
is $3.3/\SI{100}{\kilo\ohm}=\SI{33}{\micro\ampere}$, well under the
\SI{1}{\milli\ampere} limit. Which upstream rail PGOOD should report to
is an MCU-integration decision outside this section's scope; the pin-level
electrical requirements are satisfied.

\subsection{Output setpoint and trim-range requirement}\label{sec:hv-setpoint}

\subsubsection{Ignition margin}\label{sec:hv-ignition}

Before ignition a tube draws no current, so the full rail appears across the
selected gap: the IN-12B's guaranteed $\le\SI{170}{\volt}$ ignition ceiling
(\cref{sec:in12b}) is therefore a zero-margin floor (the IN-6's \SI{140}{\volt}
ceiling is never limiting). This document adds a flat \SI{15}{\volt} margin on
top of that floor, undifferentiated by cause, to cover strike-voltage and
trim-mechanism uncertainty the datasheet does not quantify, giving a
\SIrange{170}{185}{\volt} band. \textbf{The output setpoint must be capable of
reaching anywhere across \SIrange{170}{185}{\volt}.} A single fixed
ballast and divider reaches only a narrow, few-volt window while staying within
the tube's current limits (\cref{sec:hv-load-digit}), far short of that
\SI{15}{\volt} band; \cref{sec:hv-divider-split} accordingly provides a table of
ballast/R205 pairs rather than a single value, with the ballast and divider
tuned together against the installed tubes as part of board construction.

\subsubsection{Interpretation of the datasheet's 200/250~V anode-supply figures}\label{sec:hv-anode-figures}

The IN-12B datasheet separately states a minimum anode supply of \SI{200}{\volt} and
a recommended \SI{250}{\volt}~DC, both above the \SIrange{170}{185}{\volt} margin
band derived above. The working hypothesis of \cref{sec:in12b} is that these figures serve the
tube's other specified supply mode (unfiltered half-wave-rectified AC), in
which the tube must re-ignite every mains cycle and conducts only near the crest, so
the supply must carry substantial peak headroom above the ignition voltage merely to
achieve a usable conduction angle and average brightness. A regulated, continuously
present DC rail faces neither constraint: ignition happens once per power-up, and
the operating point is fixed by the ballast. On that reading, the physically
grounded DC requirements are exactly the ones derived above: guaranteed strike
($\ge V_{\mathrm{ign,max}}$ plus margin) and cathode current held inside the
specified band by ballast sizing (\cref{sec:hv-load}, below), both achievable
anywhere within the \SIrange{170}{185}{\volt} margin band. This interpretation is not confirmed by the source
document, and is carried as an accepted-with-rationale assumption: if the
\SI{200}{\volt} minimum in fact encodes an additional DC-mode requirement, the
design is relying on the verified $\le\SI{170}{\volt}$ ignition line instead of it.
The off-state cathode-voltage exposure of the unselected K155ID1 outputs at
$V_{\mathrm{HV}}$ was analyzed and accepted in \cref{sec:bcd-voltage-risk}; the
range derived here (\SIrange{170}{185}{\volt}) is within the envelope that
acceptance was conditioned on.

\subsubsection{Operating points used throughout this section}\label{sec:hv-points}

Two operating points recur throughout, bracketing the converter's trim range rather
than pinning it to one exact setpoint:
\begin{description}
  \item[Nominal] $V_{\mathrm{BUS}} = \SI{9}{\volt}$ (the lower USB-PD contract),
    output at \SI{170}{\volt} (chosen as a convenient reference point coinciding
    with the IN-12B's guaranteed ignition ceiling, \cref{sec:hv-ignition}), tube
    currents at their expected (not worst-case) values.
  \item[Design-max envelope] $V_{\mathrm{BUS}} = \SI{8.5}{\volt}$ (bottom of the input
    window, worst case for primary current), output at \SI{191.5}{\volt}, and every
    digit tube simultaneously at its datasheet-maximum \SI{3.5}{\milli\ampere}
    current. \SI{191.5}{\volt} is the voltage the widest-ballast option in
    \cref{sec:hv-divider-split}'s table reaches at exactly
    \SI{3.5}{\milli\ampere}: a corner the design can reach in service, not a
    hypothetical tolerance stack.
\end{description}

\paragraph{Achieved tuning range.}\label{sec:hv-achieved-range}
\Cref{sec:hv-load-digit,sec:hv-divider-split} show that the digit ballast and the
feedback-divider resistor it pairs with are not independent, separately-fixed
values but a matched pair, chosen together from a table of standard-value
options. Because each option's own rated-current window
(\SIrange{2.5}{3.5}{\milli\ampere}, \cref{sec:in12b}) maps to a different
voltage, the range this design must tolerate in service is wider than the
\SIrange{170}{185}{\volt} requirement derived above: \textbf{$V_{\mathrm{HV}}$
may be deliberately tuned anywhere from \SI{164.8}{\volt} to
\SI{191.5}{\volt}}, depending on which table entry a given board uses. Calculations that check component \emph{safety} (that a rating or
destructive threshold is not exceeded, e.g.\ rectifier and capacitor voltage
ratings, switch and clamp stress) use this wider envelope. Calculations that
check whether something \emph{works as intended}, e.g.\ a tube current sitting
inside its rated band, need only hold across the narrower
\SIrange{170}{185}{\volt} design range: the wider envelope exists so components
merely survive an excursion outside it, not so they perform ideally there.

\subsection{Ballast sizing}\label{sec:hv-load}

\subsubsection{Digit tubes (NX1--NX4, ballasts R1--R4)}\label{sec:hv-load-digit}

Each IN-12B anode is fed from $V_{\mathrm{HV}}$ through its ballast; the selected cathode
returns through a K155ID1 output, sinking the tube's own rated DC cathode
current $I_K \in \SIrange{2.5}{3.5}{\milli\ampere}$ (\cref{sec:in12b}). The
ballast equation is
\begin{align*}
  R_A &= \frac{V_{\mathrm{rail}} - V_M - V_K}{I_K},
\end{align*}
with maintaining voltage $V_M = \SI{145}{\volt}$ (typical, no tabulated spread;
\cref{sec:in12b}) and $V_K$ the K155ID1's on-state (saturation) drop at the
selected output. The driver's \SI{2.5}{\volt} maximum $V_K$ is specified at a
\SI{7}{\milli\ampere} test current (\cref{sec:bcd-driver}), at least double
$I_K$'s \SIrange{2.5}{3.5}{\milli\ampere} range, so \SI{2.5}{\volt} serves as a
conservative (over-)estimate of $V_K$ at this design's lower current, and
\SI{1.0}{\volt} as the expected value (assumption: saturation drop falls
roughly with collector current; the true value is bounded below by a few
hundred millivolts). The sizing below uses the \SI{1.0}{\volt} expected value
throughout rather than stacking the full $V_K$ uncertainty on top of every other
tolerance: the resulting worst-case current error,
$\Delta V_K/R_{A,\min} \approx \SI{1.5}{\volt}/\SI{7.50}{\kilo\ohm} \approx
\SI{0.20}{\milli\ampere}$ (using the smallest ballast in
\cref{sec:hv-divider-split}'s table, the worst case since the error scales
inversely with $R_A$), is small compared with the rated window's own
\SI{0.5}{\milli\ampere} half-width, so it is absorbed by that window rather than
propagated as a separate correction term.

The design's required trim range (\SIrange{170}{185}{\volt},
\cref{sec:hv-ignition}) is too wide to be accommodated by a single ballast
resistor value: a ballast sized to keep the cathode current inside its rated
\SIrange{2.5}{3.5}{\milli\ampere} band at the low end of that range pushes it
outside the band at the high end, and vice versa. The ballast and the divider
resistor that sets the trim range around it (R205,
\cref{sec:hv-divider-split}) are therefore not selected independently.
\Cref{sec:hv-divider-split} derives a table of standard-value ballast/R205
pairs, each with its own \emph{tuning targets} $V_{\mathrm{min}}$--$V_{\mathrm{max}}$:
the voltages that drive exactly \SIrange{2.5}{3.5}{\milli\ampere} through that
row's ballast. Those targets are not the same thing as the trimmer's full
physical travel, which extends well past $V_{\mathrm{min}}$ and $V_{\mathrm{max}}$
in both directions (\cref{sec:hv-divider-split}'s $V_{\mathrm{floor,wc}}$/
$V_{\mathrm{ceil,wc}}$ columns) to ensure that the full $V_{\mathrm{min}}$--$V_{\mathrm{max}}$
range is achievable with worst-case part tolerances.

The ballast is not pinned to one row: R1--R4 may be any digit-ballast value in
\cref{tab:hv-ballast-divider} (currently \SIrange{7.50}{13.00}{\kilo\ohm}),
paired with the matching R205, and every calculation that depends on the
ballast choice is checked across the table's full range rather than at one
assumed value. For example, the \SI{10.00}{\kilo\ohm} row gives
\begin{align*}
  I_K(V_{\mathrm{min}} = \SI{171.0}{\volt}) &= \SI{2.5}{\milli\ampere}, &
  I_K(V_{\mathrm{typ}} = \SI{176.0}{\volt}) &= \SI{3.0}{\milli\ampere}, &
  I_K(V_{\mathrm{max}} = \SI{181.0}{\volt}) &= \SI{3.5}{\milli\ampere},
\end{align*}
by construction. Worst-case dissipation grows with $R_A$ at the shared
\SI{3.5}{\milli\ampere} rated maximum, so the table's largest entry bounds
every row:
\begin{align*}
  I_K^2 R_A = 3.5^2 \times 13.00 \approx \SI{159}{\milli\watt},
\end{align*}
still well inside a DIN0207 axial part's $\approx\SI{0.6}{\watt}$ rating
($\approx$27\,\%). Specification: R1--R4
$\in \SIrange{7.50}{13.00}{\kilo\ohm}$ (\cref{tab:hv-ballast-divider}); R205
selected to match per that table.

The IN-12B decimal-point cathode has no assigned driver signal in this design and
carries zero current.

\subsubsection{Colon tubes (NX5--NX6, ballasts R5--R6)}\label{sec:hv-load-colon}

For the IN-6, the conservative maintaining figure is \SI{90}{\volt}
(\cref{sec:in6}; the higher of the two datasheet figures is used because it
minimizes the computed current, which is the pessimistic direction for the
lower current bound). Unlike the digit ballasts, this is achievable with a
single resistor value, so a single fixed value is derived here rather than a
table.

Sized against the datasheet's wider \SIrange{0.45}{1.3}{\milli\ampere}
operating-current rating (\cref{sec:in6}), which need only hold safely across
the full \SIrange{164.8}{191.5}{\volt} achieved range (\cref{sec:hv-achieved-range})
rather than the tube performing ideally there:
\begin{align*}
  V_{\mathrm{drop}}(\SI{164.8}{\volt}) &= 164.8 - 90 - 2.5 = \SI{72.3}{\volt}, &
  V_{\mathrm{drop}}(\SI{191.5}{\volt}) &= 191.5 - 90 - 2.5 = \SI{99.0}{\volt},
\end{align*}
\begin{align*}
  R_A &\in \left[\frac{\SI{99.0}{\volt}}{\SI{1.3}{\milli\ampere}},\;
               \frac{\SI{72.3}{\volt}}{\SI{0.45}{\milli\ampere}}\right]
       = [\SI{76.2}{\kilo\ohm},\, \SI{160.7}{\kilo\ohm}].
\end{align*}
A value of \SI{120}{\kilo\ohm} sits near the middle of this band, and
also keeps current within the tighter, recommended
\SIrange{0.6}{0.85}{\milli\ampere} window (\cref{sec:in6}) across the narrower
\SIrange{170}{185}{\volt} design range: $I = \SI{0.646}{\milli\ampere}$ at
\SI{170}{\volt} and $I = \SI{0.771}{\milli\ampere}$ at \SI{185}{\volt}.
Specification: R5--R6 $= \SI{120}{\kilo\ohm}$.

\subsection{Feedback divider design}\label{sec:hv-divider}

\subsubsection{Divider current selection}\label{sec:hv-divider-current}

The total feedback-divider current at the operating point is a free parameter,
constrained from above and below rather than fixed by any single requirement.

\textbf{Lower bound: power cost.} The divider is a permanent load on
$V_{\mathrm{HV}}$, drawing current whenever the converter is enabled, tube
state notwithstanding. The tube currents established in
\cref{sec:hv-load} total on the order of \SI{13}{\milli\ampere}; a divider current
three orders of magnitude smaller costs a proportionally negligible fraction of
that (\cref{sec:hv-budget} tallies the exact figure once every contributor is
known). Shrinking it further therefore recovers no efficiency worth having,
while pushing the divider current toward whatever bias or leakage current the FB
pin itself draws (next paragraph): the margin between the intentional current
and the parasitic one narrows, trading an unmeasurable power saving for a
resolvable accuracy risk.

\textbf{Upper bound: feedback-node integrity.} Raising the divider
resistance to shave the remaining power cost trades against two effects that
both push the setpoint error the wrong way: any bias or leakage current at
the FB pin becomes a larger fraction of the divider current (and therefore a
larger apparent shift in the voltage the divider presents to $V_{REF}$), and
the divider node's higher impedance couples more readily to switching noise
radiated a few millimeters away by Q201 and T201. The LM5155 characteristics
extracted in \cref{sec:lm5155} do not report an FB bias or leakage current
figure, so this bound cannot be pinned to a sourced number.
FB leakage is
assumed to stay within the low-nanoamp class typical of comparator-input
feedback pins on this class of controller. A total divider current on the
order of \SI{100}{\micro\ampere} keeps that assumed leakage four to five
orders of magnitude below the intentional divider current, wide enough that
the assumption's exact value is not critical.

\SI{100}{\micro\ampere} at the \SI{170}{\volt}
reference point sets a target total divider resistance of
$(170-1)\,\si{\volt}/\SI{100}{\micro\ampere} \approx \SI{1.69}{\mega\ohm}$.

\subsubsection{Resistor split and trim range}\label{sec:hv-divider-split}

The required output range (\SIrange{170}{185}{\volt}, \cref{sec:hv-ignition}) sets
how the total divider resistance (\cref{sec:hv-divider-current}) splits between a
fixed upper leg and a partly-adjustable lower leg: $R_{\mathrm{upper}} \rightarrow
\mathrm{FB} \rightarrow R_{\mathrm{lower}} \rightarrow \mathrm{GND}$, with
$V_{\mathrm{out}} = V_{\mathrm{REF}}(1+R_{\mathrm{upper}}/R_{\mathrm{lower}})$ and
$V_{\mathrm{REF}} = \SI{1.00}{\volt}$ (\cref{sec:lm5155}). Solving for the split gives
$R_{\mathrm{upper}}/R_{\mathrm{lower}} = V_{\mathrm{out}}/V_{\mathrm{REF}} - 1$, which
at the \SI{170}{\volt} nominal reference point is
\begin{align*}
  \frac{R_{\mathrm{upper}}}{R_{\mathrm{lower}}} = \frac{170}{1.00} - 1 = 169.
\end{align*}
$R_{\mathrm{lower}}$ therefore contributes under $1\,\%$ of the total series
resistance, negligible for setting the total divider current
(\cref{sec:hv-divider-current}), though it still fixes the trim range together with
R205 (below). $R_{\mathrm{upper}}$ is accordingly set to the \SI{1.69}{\mega\ohm}
target of \cref{sec:hv-divider-current} exactly, split across two equal resistors
as is standard practice for a high-voltage divider, halving the voltage each
element must withstand (\cref{sec:hv-divider-stress}): R203 = R204 =
\SI{845}{\kilo\ohm}, a standard E96 value giving $R_{\mathrm{upper}} =
\SI{1.69}{\mega\ohm}$ total, an exact match to the target. $R_{\mathrm{lower}}$ is
then sized, row by row, to achieve the required trim range.

$R_{\mathrm{lower}}$ comprises a fixed resistor R205 in series with a trimmer RV201
($R_{\mathrm{lower}} = R205 + R_V$, $0 \le R_V \le R_{V,\mathrm{tot}}$), which
provides the field adjustment. $R_{V,\mathrm{tot}} = \SI{2}{\kilo\ohm}$ is sized so
the trimmer's mechanical travel spans $V_{\min}$ to $V_{\max}$ for every row of
\cref{tab:hv-ballast-divider}, across the worst-case tolerances of every divider
component (R203/R204, R205, $V_{\mathrm{REF}}$, and the trimmer's own assumed
$\pm10\,\%$ total-resistance tolerance). For each candidate ballast, R205 is then
chosen so that the trimmer's electrical midpoint ($R_V = R_{V,\mathrm{tot}}/2$)
lands at that row's $V_{\mathrm{typ}}$.

\Cref{tab:hv-ballast-divider} tabulates, for each standard-value digit ballast
$R_A$ (\cref{sec:hv-load-digit}), the R205 that centers the trimmer's travel on
that ballast's $V_{\mathrm{typ}}$, together with the tuning targets
$V_{\min}$/$V_{\mathrm{typ}}$/$V_{\max}$ and the worst-case end-stop voltages
$V_{\mathrm{floor,wc}}$/$V_{\mathrm{ceil,wc}}$.

\subsubsection{Divider element stress}\label{sec:hv-divider-stress}

Pre-strike leakage aside, R203 and R204 split $(V_{\mathrm{out}}-1)$ evenly:
\SI{84.5}{\volt} each at the \SI{170}{\volt} nominal reference point,
\SI{95.25}{\volt} each at the \SI{191.5}{\volt} design-max envelope
(\cref{sec:hv-achieved-range}). DIN0207 axial metal film parts are specified,
whose standard limiting element voltage is \SI{250}{\volt}. Margin exceeds
$2.6\times$ at the design-max envelope, and dissipation is
$95.25^2/\SI{845}{\kilo\ohm} = \SI{10.7}{\milli\watt}$. The two-resistor split
is therefore not strictly required for voltage rating with these parts, but it
keeps each element far from its limit and is retained. R205 and RV201 see about
\SI{1}{\volt}.

\subsection{Operating point and efficiency}\label{sec:hv-op}

\subsubsection{Component values assumed for the loss model}\label{sec:hv-op-inputs}

The loss model below uses four standard-practice component values whose own
sizing depends on this section's converged peak current (a mutual coupling
typical of iterative power-converter design), each verified or fully derived
at its cross-referenced point:
\begin{itemize}[nosep]
  \item Q201 is an IRL540N-type commodity through-hole logic-level power MOSFET;
  \item $R211 = \SI{10}{\ohm}$, a standard gate-drive resistor value governing
    turn-on;
  \item D203 (SB240S-E3/54) and $R214 = \SI{3.3}{\ohm}$, a turn-off speedup
    network bypassing $R211$ for acceptable turn-off loss, sized in
    \cref{sec:hv-op-losses,sec:hv-switch};
  \item $R201 = \SI{39}{\milli\ohm}$, the current-sense resistor, derived from the
    current-limit threshold and this section's converged $I_{\mathrm{pk}}$ in
    \cref{sec:hv-cs};
  \item $R212 = \SI{30}{\kilo\ohm}$, $C209 = \SI{12}{\nano\farad}$, the RCD clamp
    network, sized in \cref{sec:hv-clamp} for a target switch-voltage margin at
    the worst-case current-limited corner, minimizing clamp dissipation subject
    to that margin.
\end{itemize}

\subsubsection{Loss mechanisms}\label{sec:hv-op-losses}

In DCM the converter transfers a fixed packet of magnetizing energy each cycle:
\begin{align*}
  P_{\mathrm{in}} = \tfrac{1}{2} L_p I_{\mathrm{pk}}^2 f_{\mathrm{sw}}
  \quad\Longrightarrow\quad
  I_{\mathrm{pk}} = \sqrt{\frac{2 P_{\mathrm{in}}}{L_p f_{\mathrm{sw}}}},
  \qquad
  P_{\mathrm{in}} = \frac{P_{\mathrm{out}}}{\eta}.
\end{align*}
Efficiency is derived by iteration: guess $\eta$, compute $P_{\mathrm{in}}$
and $I_{\mathrm{pk}}$, evaluate each loss mechanism, recompute $\eta$, repeat to
convergence. The loss models and their inputs:
\begin{description}[style=nextline]
  \item[Primary conduction] Triangular current over $t_{\mathrm{on}}$:
    $I_{\mathrm{rms}} = I_{\mathrm{pk}}\sqrt{D/3}$ through
    $R_{DS(\mathrm{on})} + R_{201} + R_{\mathrm{DCR,pri}}
     = 55 + 39 + 13 = \SI{107}{\milli\ohm}$. $R_{DS(\mathrm{on})}$ is derived,
    not assumed, from two separate corrections to the datasheet's maxima. The
    datasheet tabulates $R_{DS(\mathrm{on})}$ at only two $V_{GS}$ points,
    both at $T_J=\SI{25}{\celsius}$: \SI{53}{\milli\ohm} at
    $V_{GS}=\SI{5.0}{\volt}$ and \SI{44}{\milli\ohm} at $V_{GS}=\SI{10}{\volt}$
    (\ds{infineon-irl540n-datasheet-en.pdf}{2}); linearly interpolating to
    this design's own \SI{6.85}{\volt} gate rail gives a cold value of
    $\approx\SI{49.7}{\milli\ohm}$. $R_{DS(\mathrm{on})}$ then rises with
    junction temperature above that 25\,\si{\celsius} reference point
    (\ds{infineon-irl540n-datasheet-en.pdf}{3}, Fig.\,4, ``Normalized
    On-Resistance vs.\ Temperature''; read as a local linear approximation
    between its $1.0\times$-at-\SI{25}{\celsius} and
    $2.4\times$-at-\SI{175}{\celsius} anchors, since no intermediate points
    are tabulated), and Q201's own dissipation, which $R_{DS(\mathrm{on})}$
    itself partly sets, determines that temperature. Solved self-consistently
    against the design-max loss budget below
    ($\SI{25}{\celsius}$ ambient assumed; this bench board has no enclosure
    or thermal spec to anchor a different figure), the converged operating
    point is $T_J \approx \SI{37}{\celsius}$,
    $R_{DS(\mathrm{on})} \approx \SI{55}{\milli\ohm}$.

  \item[Turn-off overlap]
    The IRL540N datasheet (\ds{infineon-irl540n-datasheet-en.pdf}{2}) specifies
    the gate-drain (Miller) charge only as a guaranteed maximum, $Q_{GD} \le
    \SI{38}{\nano\coulomb}$, with no typical value tabulated; its gate-charge
    curve (\ds{infineon-irl540n-datasheet-en.pdf}{4}, Fig.\,6) shows the Miller
    plateau sitting at $V_{\mathrm{plateau}} \approx \SI{3}{\volt}$. The same
    datasheet's resistive-load switching-time table gives $t_f =
    \SI{62}{\nano\second}$ typical at its own test condition
    ($R_G=\SI{5.0}{\ohm}$, $V_{GS}$ pulse $=\SI{5.0}{\volt}$), which implies a
    typical $Q_{GD} \approx t_f \times (5.0-3.0)/5.0\,\si{\ohm} \approx
    \SI{25}{\nano\coulomb}$ at that test point. The LM5155's own output stage adds
    an internal pull-down resistance in series with $R211$. Its datasheet
    (\ds{lm5155.pdf}{7}, MOSFET DRIVER) gives the low-state output's voltage
    drop under an externally forced \SI{100}{\milli\ampere} as \SI{0.15}{\volt},
    implying $R_{\mathrm{int}} \approx \SI{1.5}{\ohm}$ for this pull-down path
    (read as characterizing the pull-down transistor by sourcing test current
    into the pin while the driver holds it low; the datasheet table's two rows
    are not perfectly unambiguous about which pin state pairs with which current
    direction, so this reading is the best available, not a certainty).

    Turn-off overlap dominates the loss budget, which justifies actively
    reducing it rather than accepting the turn-off speed $R211$ alone
    provides. D203 (SB240S-E3/54, a through-hole DO-41 Schottky rectifier)
    in series with R214 ($\SI{3.3}{\ohm}$) bypasses $R211$ for the turn-off
    (discharge) direction only: D203's anode sits at the gate, its cathode
    at the $R211$/driver-output node, so it blocks during turn-on (charge
    current still routes entirely through $R211$, leaving that edge's speed
    and any associated ringing unchanged) and conducts during turn-off. R214
    is sized against the LM5155's stated driver capability
    (\ds{lm5155.pdf}{23}, Section 9.3.12): ``the device provides an N-channel
    MOSFET driver that can source or sink a peak current of \SI{1.5}{\ampere}.''
    The binding current is the brief pre-plateau discharge current drawn
    from the fully-enhanced gate ($\approx V_{\mathrm{drive}}$, not the
    lower Miller plateau voltage used below), which exceeds the plateau
    current itself:
    \begin{align*}
      I_{\mathrm{gate}}^{\mathrm{peak}} &= \frac{V_{\mathrm{drive}} -
        V_{F(D203)}}{R214 + R_{\mathrm{int}}}
        = \frac{6.85 - 0.5}{3.3+1.5} \approx \SI{1.32}{\ampere}
        \quad (88\,\% \text{ of the } \SI{1.5}{\ampere} \text{ rating}),
    \end{align*}
    using $V_{F(D203)} \approx \SI{0.5}{\volt}$, interpolated below the sole
    tabulated point ($\SI{0.55}{\volt}$ at \SI{2}{\ampere}) in the absence of
    a lower-current data point. The resulting margin depends on that
    interpolated diode drop and on the $R_{\mathrm{int}}$ estimate above,
    both datasheet-derived rather than measured; a bench check of the
    gate/D203 current during turn-off is warranted before treating the
    \SI{12}{\percent} headroom to the \SI{1.5}{\ampere} rating as final.

    At the (lower) Miller-plateau voltage, the turn-off gate current is
    $I_{\mathrm{gate}} = (6.85-3.0-0.5)/(3.3+1.5) \approx \SI{698}{\milli\ampere}$,
    giving
    \begin{align*}
      t_{\mathrm{ovl}}^{\mathrm{typ}} &= \frac{Q_{GD}^{\mathrm{typ}}}{I_{\mathrm{gate}}}
        \approx \SI{36}{\nano\second}, &
      t_{\mathrm{ovl}}^{\max} &= \frac{Q_{GD}^{\max}}{I_{\mathrm{gate}}}
        \approx \SI{54}{\nano\second}.
    \end{align*}
    With the commutation voltage $V_{\mathrm{com}} = V_{\mathrm{BUS}} +
    V_{\mathrm{refl}}$, $E_{\mathrm{off}} \approx \tfrac{1}{2} I_{\mathrm{pk}}
    V_{\mathrm{com}} t_{\mathrm{ovl}}$. The convergence below uses
    $t_{\mathrm{ovl}}^{\mathrm{typ}}$; \cref{sec:hv-switch} additionally checks
    Q201's dissipation at $t_{\mathrm{ovl}}^{\max}$, since that check guards
    against thermal damage rather than characterizing typical operation. Turn-on
    is near-lossless in DCM (zero current; $C_{oss}$ discharge from the
    post-ring drain voltage contributes only a few milliwatts) and is governed
    by $R211$ alone ($t_{\mathrm{ovl}}$ has no turn-on analog worth deriving).
  \item[Gate drive and controller] $P = (Q_G f_{\mathrm{sw}} + I_Q) V_{\mathrm{BUS}}$
    with $Q_G \approx \SI{40}{\nano\coulomb}$ at the \SI{6.85}{\volt} VCC rail
    (scaled from the \SI{10}{\volt} datasheet point; assumption) and controller
    operating current $I_Q \le \SI{480}{\micro\ampere}$ (\ds{lm5155.pdf}{1}). Gate
    charge is drawn through the internal VCC regulator from BIAS
    ($=V_{\mathrm{BUS}}$), so the full input voltage is charged to this loss.
  \item[RCD clamp] Leakage energy $\tfrac{1}{2} L_{\mathrm{lk}} I_{\mathrm{pk}}^2$
    per cycle, dissipated in R212 with the clamp-voltage multiplier derived in
    \cref{sec:hv-clamp}.
  \item[Rectifier] $V_F \approx \SI{1.0}{\volt}$ (ultrafast-diode class figure at
    $\sim$\SI{0.2}{\ampere}) times $I_{\mathrm{out}}$; recovery loss is negligible
    because in DCM the secondary current reaches zero before the switch turns on.
  \item[Secondary conduction] $I_{s,\mathrm{rms}}^2 \times \SI{1.60}{\ohm}$ DCR.
  \item[Capacitor ESR] Input ($\approx\SI{30}{\milli\ohm}$ polymer bulk plus
    ceramics) and output ($\approx\SI{0.5}{\ohm}$, C204, a polymer aluminum
    part) ESR; both small.
  \item[Core] Uncharacterized at this frequency; a \SI{50}{\milli\watt} allowance
    is carried.
\end{description}

\subsubsection{Converged operating point (design-max envelope)}\label{sec:hv-op-converge}

Iterating at the design-max envelope ($P_{\mathrm{out}} = \SI{3.05}{\watt}$,
$V_{\mathrm{BUS}} = \SI{8.5}{\volt}$, $V_{\mathrm{out}} = \SI{191.5}{\volt}$,
reflected voltage $V_{\mathrm{refl}} = (191.5+1)/10 = \SI{19.25}{\volt}$,
$t_{\mathrm{ovl}} = t_{\mathrm{ovl}}^{\mathrm{typ}} = \SI{36}{\nano\second}$),
from a seed of $\eta_0 = 0.85$ the loop converges to $\eta = 0.872$. The
converged cycle:
\begin{align*}
  P_{\mathrm{in}} &= \frac{3.052}{0.872} = \SI{3.50}{\watt}, &
  E_{\mathrm{cyc}} &= \frac{3.50}{149.4\times10^{3}} = \SI{23.4}{\micro\joule},\\
  I_{\mathrm{pk}} &= \sqrt{\frac{2 \times 23.4\,\si{\micro\joule}}
                                 {\SI{10}{\micro\henry}}} = \SI{2.16}{\ampere}, &
  t_{\mathrm{on}} &= \frac{L_p I_{\mathrm{pk}}}{V_{\mathrm{BUS}}}
                   = \frac{10\,\si{\micro\henry} \times 2.16}{8.5}
                   = \SI{2.54}{\micro\second},\\
  D &= t_{\mathrm{on}} f_{\mathrm{sw}} = 0.38, &
  I_{\mathrm{rms,pri}} &= I_{\mathrm{pk}}\sqrt{D/3} = \SI{0.77}{\ampere}.
\end{align*}

Two through-hole parts address the largest term in that table. The D203/R214
turn-off speedup network drops turn-off overlap from
what a plain \SI{10}{\ohm} $R211$ alone would give
(\SIrange{75}{114}{\nano\second}, itself already corrected for the LM5155's
internal driver impedance) to \SIrange{36}{54}{\nano\second}, and the
design-max efficiency band tightens to \SIrange{85.0}{87.2}{\percent}
(bounded by $t_{\mathrm{ovl}}^{\max}=\SI{54}{\nano\second}$ at the pessimistic
end). The
convergence above uses $t_{\mathrm{ovl}}^{\mathrm{typ}}$, the value real parts
cluster around; \cref{sec:hv-switch} separately checks Q201's dissipation at
$t_{\mathrm{ovl}}^{\max}$ for the case a given unit's gate charge lands toward
the guaranteed limit, and \cref{sec:hv-cs-sense} folds the same $t_{\mathrm{ovl}}$
spread into its current-limit margin analysis as a proper tolerance term. A bench
efficiency measurement remains worthwhile to confirm the sourced figures against
a real board, but is no longer the single open unknown it was.

\subsubsection{Nominal-point efficiency}\label{sec:hv-op-nominal}

The same procedure at the nominal point ($\SI{1.89}{\watt}$, \SI{9}{\volt},
\SI{170}{\volt}) converges to $\eta = 0.849$, $P_{\mathrm{in}} = \SI{2.23}{\watt}$,
$E_{\mathrm{cyc}} = \SI{14.9}{\micro\joule}$, $I_{\mathrm{pk}} = \SI{1.73}{\ampere}$,
$I_{\mathrm{in}} = \SI{0.25}{\ampere}$ average. Nominal efficiency is slightly
\emph{lower} than at design-max because the dominant turn-off loss scales as
$I_{\mathrm{pk}} \propto \sqrt{P}$, not $P$.

At the upper end of the negotiated range ($V_{\mathrm{BUS}} = \SI{12}{\volt}$,
the same \SI{1.89}{\watt}, \SI{170}{\volt} target) the procedure converges to
$\eta = 0.839$, $P_{\mathrm{in}} = \SI{2.25}{\watt}$,
$E_{\mathrm{cyc}} = \SI{15.1}{\micro\joule}$, $I_{\mathrm{pk}} = \SI{1.74}{\ampere}$,
$I_{\mathrm{in}} = \SI{0.19}{\ampere}$ average, with a shorter on-time and lower
RMS conduction current than at \SI{9}{\volt}
($I_{\mathrm{rms,pri}} = \SI{0.47}{\ampere}$ against \SI{0.53}{\ampere}).
Efficiency is nonetheless \emph{lower} at \SI{12}{\volt}: turn-off loss scales
with the commutation voltage $V_{\mathrm{com}} = V_{\mathrm{BUS}} + V_{\mathrm{refl}}$,
and the added \SI{3}{\volt} on $V_{\mathrm{BUS}}$ outweighs the conduction
saving. A higher negotiated contract voltage is therefore not a free
efficiency gain for this converter; the \SI{9}{\volt} contract used as the
nominal point throughout this section is, if anything, mildly favorable.

\subsubsection{Peak current at minimum inductance}\label{sec:hv-op-lmin}

With the minimum-tolerance inductance ($L_p = \SI{9}{\micro\henry}$ at rated peak
current, \cref{sec:da2032}), the same energy packet requires
\begin{align*}
  I_{\mathrm{pk}}^{(L\min)} &= \sqrt{\frac{2 \times 23.4\,\si{\micro\joule}}
                                          {\SI{9}{\micro\henry}}}
                             = \SI{2.28}{\ampere},
\end{align*}
the worst-case commanded peak used in \cref{sec:hv-cs}.

\subsection{DCM verification}\label{sec:hv-dcm}

DCM requires $t_{\mathrm{on}} + t_{\mathrm{dem}} < T$ with margin for the drain
ring-down. The demagnetization time, referred through the 1:10 ratio, is
\begin{align*}
  t_{\mathrm{dem}} &= \frac{n L_p I_{\mathrm{pk}}}{V_{\mathrm{out}} + V_F}.
\end{align*}
The binding corner is the one that maximizes $t_{\mathrm{on}} + t_{\mathrm{dem}}$:
maximum inductance ($\SI{11}{\micro\henry}$, $+10\,\%$), minimum input
(\SI{8.5}{\volt}), design-max load. There
\begin{align*}
  I_{\mathrm{pk}} &= \sqrt{\frac{2\times23.4\,\si{\micro\joule}}{\SI{11}{\micro\henry}}}
                   = \SI{2.06}{\ampere},\\
  t_{\mathrm{on}} &= \frac{11\,\si{\micro\henry}\times 2.06}{8.5}
                   = \SI{2.67}{\micro\second}, &
  t_{\mathrm{dem}} &= \frac{10 \times 11\,\si{\micro\henry} \times 2.06}{192.5}
                   = \SI{1.18}{\micro\second},\\
  t_{\mathrm{on}} + t_{\mathrm{dem}} &= \SI{3.85}{\micro\second}
    = 0.58\,T, &
  t_{\mathrm{idle}} &= \SI{2.84}{\micro\second}.
\end{align*}
DCM holds with a 42\,\% idle fraction at the worst corner; at \SI{13}{\volt} input
or lighter load the margin only grows (at the minimum trim setpoint the load the
ballasts can draw falls faster than the demagnetization slope degrades). The duty
cycle never exceeds 0.40, far under the controller's $\approx$0.91 maximum near
this frequency, and $t_{\mathrm{on}} \ge \SI{2.6}{\micro\second}$ is more than an
order of magnitude above the $\approx\SI{165}{\nano\second}$ minimum on-time
(\cref{sec:lm5155}). Since $D < 0.5$ in DCM everywhere, no slope compensation is
required for stability, consistent with the omission of $R_{SL}$
(\cref{sec:hv-cs}). Verified.

\subsection{Current sensing and current limit}\label{sec:hv-cs}

\subsubsection{CS filter}\label{sec:hv-cs-filter}

With the \SI{100}{\milli\volt} (93--107) current-limit threshold of
\cref{sec:lm5155} and R201 $= \SI{39}{\milli\ohm}$ (declared in
\cref{sec:hv-op-inputs}):
\begin{align*}
  I_{\mathrm{lim}}^{\mathrm{typ}} &= \frac{\SI{100}{\milli\volt}}{\SI{39}{\milli\ohm}}
    = \SI{2.56}{\ampere},\\
  I_{\mathrm{lim}}^{\min} &= \frac{\SI{93}{\milli\volt}}{39\,\si{\milli\ohm}\times1.01}
    = \SI{2.36}{\ampere}, &
  I_{\mathrm{lim}}^{\max} &= \frac{\SI{107}{\milli\volt}}{39\,\si{\milli\ohm}\times0.99}
    = \SI{2.77}{\ampere}.
\end{align*}
The CS pin taps the sense node through a filter, $R213$ in series with $C210$ to
ground; no $R_{SL}$ is used, so the current-limit comparator's threshold stays
duty-independent, which is TI's own recommendation for accurate limiting. The
filter's time constant $\tau = R_{213}C_{210}$ has both a floor and a ceiling. TI's own
timing criteria for valid duty-independent limiting (on-time above $2R_FC_F$ and
off-time above $3R_FC_F$) are satisfied by orders of magnitude at this
converter's operating point ($t_{\mathrm{on}} \ge \SI{2.6}{\micro\second}$,
$(1-D)/f_{\mathrm{sw}} \approx \SI{3.9}{\micro\second}$,
\cref{sec:hv-op-converge}), so they do not meaningfully constrain the choice. Two
other requirements do.

\textbf{Upper bound: limit-shift error.} The filter delays the sampled current by
$\Delta I_{\mathrm{delay}} = (V_{\mathrm{BUS}}/L_p)\,\tau$, which the controller
reads as extra peak current before its comparator trips, an apparent upward
shift of the current limit. Keeping that shift under half the
$I_{\mathrm{lim}}^{\min}$--$I_{\mathrm{lim}}^{\max}$ spread above
(\SI{0.205}{\ampere} half-spread) bounds
\begin{align*}
  \tau < \frac{\SI{0.205}{\ampere}}{(V_{\mathrm{BUS}}/L_p)_{\max}}
       = \frac{\SI{0.205}{\ampere}}{\SI{1.44}{\ampere\per\micro\second}}
       = \SI{142}{\nano\second},
\end{align*}
evaluated at the fastest observed slope (\SI{13}{\volt}, \SI{9}{\micro\henry}).

\textbf{Lower bound: spike attenuation.} The leading-edge current spike the filter
exists to remove (gate current and $C_{oss}$ discharge returning through the
sense resistor at turn-on, duration tens of nanoseconds) would pass through
largely unfiltered if $\tau$ were well under that duration.

$R213 = \SI{100}{\ohm}$ and $C210 = \SI{470}{\pico\farad}$, both standard values
inside TI's recommended per-component ranges (\SIrange{10}{200}{\ohm},
\SIrange{100}{2000}{\pico\farad}), sit inside this window:
\begin{align*}
  \tau = R_{213}C_{210} = 100 \times 470\,\si{\pico\farad} = \SI{47}{\nano\second},
\end{align*}
comparable to the spike duration and well under the \SI{142}{\nano\second}
ceiling: $\Delta I_{\mathrm{delay}} \approx \SI{40}{\milli\ampere}$, under half
the tolerance-band spread as required. Combined with an assumed
\SI{50}{\nano\second} comparator/driver delay, total overshoot past the threshold
at the fastest slope is $\Delta I_{\mathrm{ovs}} \approx \SI{0.14}{\ampere}$, used
in \cref{sec:hv-cs-sense} below.

\subsubsection{Sense resistor and limit thresholds}\label{sec:hv-cs-sense}

R201 carries the switch current to ground; with the current-limit thresholds of
\cref{sec:hv-cs-filter} and the filter's overshoot $\Delta I_{\mathrm{ovs}}
\approx \SI{0.14}{\ampere}$, the sense resistor must satisfy two opposing
constraints:
\begin{align*}
  \text{power delivery:}\quad
    R_{S} &< \frac{\SI{93}{\milli\volt}}{I_{\mathrm{pk}}^{(L\min)}}
          = \frac{93\,\si{\milli\volt}}{2.28\,\si{\ampere}} = \SI{40.7}{\milli\ohm},\\
  \text{core protection:}\quad
    R_{S} &> \frac{\SI{107}{\milli\volt}}{I_{\mathrm{sat}} - \Delta I_{\mathrm{ovs}}}
          = \frac{107\,\si{\milli\volt}}{3.0 - 0.14\,\si{\ampere}} = \SI{37.4}{\milli\ohm},
\end{align*}
a \SI{3.3}{\milli\ohm} nominal window, fixed by the transformer's saturation
rating and the CS filter's overshoot on the core-protection side; neither bound
depends on $V_{\mathrm{out}}$. \SI{39}{\milli\ohm} (declared in
\cref{sec:hv-op-inputs}) sits reasonably centered in it: \SI{1.7}{\milli\ohm}
under the power-delivery ceiling and \SI{1.6}{\milli\ohm} above the
core-protection floor. Both bounds above are worst-case-additive: minimum
datasheet threshold, R201 at its own tolerance extreme, and (power-delivery
side) $L_p$ at its $-10\,\%$ extreme, all stacked simultaneously in the same
unlucky direction.

\textbf{Worst-case stacking is the wrong tool for this specific check.} Unlike a
voltage or thermal rating, where exceeding the bound risks real component
damage, exceeding this margin has a purely graceful consequence: the
controller's cycle-by-cycle current limit (no hiccup or latch-off exists on the
LM5155 variant specified here, \cref{sec:hv-ss}) terminates each
switching cycle early, delivering less energy than the voltage loop is
asking for. $V_{\mathrm{HV}}$ sags slightly below its commanded setpoint and the
tubes run marginally dimmer at that corner; no part sees more current or
voltage than the nominal design-max case assumes, since limiting the peak
current can only reduce stress on Q201, D201, and the transformer relative to
that assumption, never increase it. Given that, treating independent,
uncorrelated tolerance contributors as if they all landed at their own worst
extreme simultaneously is needlessly pessimistic for a check whose failure mode
is a soft brightness dip, not a destructive event: root-sum-square (RSS)
combination (standard practice for independent tolerance contributors feeding a
non-destructive limit) is used instead. Q201's turn-off overlap
(\cref{sec:hv-op-losses}) belongs in this same combination: the datasheet
sources it as a bounded, part-to-part manufacturing spread
(\SIrange{36}{54}{\nano\second}, independent of threshold, R201, and $L_p$), the same
character as the other three contributors, not an open-ended modeling
uncertainty that would need to be carried separately.

Isolating each contributor's effect on the margin
$M = I_{\mathrm{lim,min}} - I_{\mathrm{pk}}^{(L\min)}$ one at a time from the
all-nominal baseline ($M_{\mathrm{nom}} = \SI{0.399}{\ampere}$, using
$\SI{100}{\milli\volt}/\SI{39}{\milli\ohm}$ against $I_{\mathrm{pk}}$ at
$L_p=\SI{10}{\micro\henry}$, $t_{\mathrm{ovl}}=t_{\mathrm{ovl}}^{\mathrm{typ}}$):
\begin{align*}
  \Delta_{\mathrm{threshold}} &= \SI{-0.180}{\ampere}, &
  \Delta_{R201} &= \SI{-0.025}{\ampere}, &
  \Delta_{L_p} &= \SI{-0.117}{\ampere}, &
  \Delta_{t_{\mathrm{ovl}}} &= \SI{-0.030}{\ampere}.
\end{align*}
Worst-case-additive sums these directly: $M_{\mathrm{wc}} = 0.399 - 0.180 - 0.025
- 0.117 - 0.030 = \SI{+0.047}{\ampere}$ ($+2.0\,\%$ of $I_{\mathrm{lim,min}}$):
the sourced turn-off-overlap spread is narrow enough that this check now
clears even the fully pessimistic stack, unlike the wider, unsourced band it
replaced. RSS combines the same four in quadrature for a more representative
figure:
\begin{align*}
  M_{\mathrm{RSS}} &= M_{\mathrm{nom}} - \sqrt{\Delta_{\mathrm{threshold}}^2 +
    \Delta_{R201}^2 + \Delta_{L_p}^2 + \Delta_{t_{\mathrm{ovl}}}^2}
   = 0.399 - 0.218 = \SI{+0.181}{\ampere}
  \quad (+7.7\,\% \text{ of } I_{\mathrm{lim,min}}),
\end{align*}
an adequate margin under either treatment. The threshold specification dominates
the combination; R201's own tolerance contributes little. \textbf{This RSS
treatment is scoped to this one check}; every voltage- and thermal-rating
margin elsewhere in this document remains worst-case-additive, since those
checks guard against destructive outcomes where a statistical treatment would
not be appropriate.

On the other side, the maximum clamped peak plus overshoot reaches
$2.77 + 0.14 = \SI{2.91}{\ampere}$ against the \SI{3.0}{\ampere} transformer
rating: a 3\,\% margin, acceptable only because the \SI{3.0}{\ampere} figure is
a soft-saturation point ($L$ already specified at \SI{9}{\micro\henry} there), not
a cliff.

R201 dissipation is $I_{\mathrm{rms}}^2 R_S = 0.77^2 \times 0.039 =
\SI{23}{\milli\watt}$, trivial in a 2512.

\subsection{RCD clamp}\label{sec:hv-clamp}

At turn-off the leakage inductance ($L_{\mathrm{lk}} \le \SI{0.150}{\micro\henry}$,
\cref{sec:da2032}) carries $I_{\mathrm{pk}}$ and has nowhere to deliver it: the
magnetizing current transfers into the secondary through D201 as intended, but
the leakage current is not magnetically coupled to that path, so left unclamped
it dumps into the switch node's parasitic capacitance and rings the drain to a
spike limited only by whatever breaks down first. D202, C209, and R212 give that
current a controlled destination: D202 turns on once the drain rises to
the clamp voltage, steering the leakage current into C209 and away from the
uncontrolled ring, and R212 discharges C209 between cycles so the clamp voltage
settles to a steady value instead of climbing indefinitely. The pair returns
to $V_{\mathrm{BUS}}$, not to ground, so C209 stands off only the clamp
voltage $V_{\mathrm{cl}}$ itself (not $V_{\mathrm{BUS}} + V_{\mathrm{cl}}$), and
R212's discharge current is recycled into the input rail rather than dumped to
ground.

\subsubsection{Leakage energy and the sizing current}

Per cycle the leakage inductance delivers $E_{\mathrm{lk}} = \tfrac{1}{2}
L_{\mathrm{lk}} I_{\mathrm{pk}}^2$ into the clamp. Two currents matter, serving
different purposes:
\begin{itemize}[nosep]
  \item \textbf{Normal design-max operation}, $I_{\mathrm{pk}} =
    \SI{2.16}{\ampere}$ (\cref{sec:hv-op-converge}):
    $E_{\mathrm{lk}} = \tfrac{1}{2}\times\SI{0.15}{\micro\henry}\times 2.16^2
    \approx \SI{0.350}{\micro\joule}$, $E_{\mathrm{lk}} f_{\mathrm{sw}}
    \approx \SI{52.3}{\milli\watt}$. This sets the clamp's steady dissipation
    carried in the loss budget (\cref{sec:hv-op-losses}).
  \item \textbf{Worst case}: the current the leakage inductance carries at
    turn-off is bounded by the current limit, not by the load model. The
    guaranteed-maximum clamped peak, including the CS filter's overshoot, is
    \SI{2.91}{\ampere} (\cref{sec:hv-cs-sense}), and because the specified
    LM5155 variant has no hiccup or latch-off (\cref{sec:hv-ss}),
    current-limited operation under an output overload can persist
    indefinitely: this is a sustained corner, not a brief transient.
    $E_{\mathrm{lk}} = \tfrac{1}{2}\times\SI{0.15}{\micro\henry}\times 2.91^2
    \approx \SI{0.635}{\micro\joule}$, $E_{\mathrm{lk}} f_{\mathrm{sw}}
    \approx \SI{94.9}{\milli\watt}$.
\end{itemize}
Clamp sizing controls a voltage rating (Q201's drain, below), a destructive
failure mode, so the sizing below uses the worst-case corner, per the
tolerance-treatment scoping in \cref{sec:hv-cs-sense}; the loss budget uses
the normal-operation figure.

\subsubsection{Clamp energy multiplier}

The clamp absorbs more than the bare leakage energy. While D202 conducts, the leakage
inductor's current decays linearly from $I_{\mathrm{pk}}$ to zero, driven by the
difference between the clamped drain and the reflected secondary voltage
$V_{\mathrm{refl}} = \SI{19.25}{\volt}$ (\cref{sec:hv-op-converge}) that the
coupled winding holds at its own terminal:
\begin{align*}
  t_1 = \frac{L_{\mathrm{lk}} I_{\mathrm{pk}}}{V_{\mathrm{cl}} - V_{\mathrm{refl}}}.
\end{align*}
The charge this delivers to the clamp is the area under that linear ramp,
$Q_{\mathrm{cl}} = \tfrac{1}{2} I_{\mathrm{pk}} t_1$, but it arrives at the clamp
voltage $V_{\mathrm{cl}}$, not at the smaller voltage $V_{\mathrm{cl}} -
V_{\mathrm{refl}}$ that drives the current down. Both quantities
integrate the same current ramp, so their ratio is the ratio of the two
voltages:
\begin{align*}
  E_{\mathrm{cl}} = V_{\mathrm{cl}} Q_{\mathrm{cl}}
    = \tfrac{1}{2} L_{\mathrm{lk}} I_{\mathrm{pk}}^2 \cdot
      \frac{V_{\mathrm{cl}}}{V_{\mathrm{cl}} - V_{\mathrm{refl}}}
    = E_{\mathrm{lk}} \cdot
      \frac{V_{\mathrm{cl}}}{V_{\mathrm{cl}} - V_{\mathrm{refl}}}.
\end{align*}
At steady state this equals R212's dissipation, giving the design equation the
rest of this section solves:
\begin{align*}
  \frac{V_{\mathrm{cl}}^2}{R_{212}}
    = E_{\mathrm{lk}} f_{\mathrm{sw}}
      \frac{V_{\mathrm{cl}}}{V_{\mathrm{cl}} - V_{\mathrm{refl}}}.
\end{align*}

\subsubsection{Target clamp voltage}

$V_{\mathrm{cl}}$ is bounded below by clamp effectiveness and above by switch
stress. Below roughly $2\times$ the reflected voltage, a clamp does not compress
the spike by much (conventional guidance for this topology); above, the ceiling
is set by how much of Q201's \SI{100}{\volt} rating (\cref{sec:hv-op-inputs}) can
be spent on $V_{\mathrm{cl}}$ once $V_{\mathrm{BUS,max}}$ and D202's forward drop
are also charged against it:
\begin{align*}
  V_{DS,\mathrm{pk}} = V_{\mathrm{BUS,max}} + V_{\mathrm{cl}} + V_{F(D202)}.
\end{align*}
Commercial power-electronics practice commonly derates semiconductor voltage
stress to about 80\,\% of the rated maximum (a $20\,\%$ margin); tighter
derating (around 70\,\%, a $30\,\%$ margin) is typical where a formal
reliability specification applies. This design carries no such specification, so
the commercial figure is adopted: target margin $m = 20\,\%$. D202's forward
drop is not fixed by a part choice at this point in the derivation; a
conservative \SI{1.5}{\volt}, toward the high end of what small fast or
ultrafast rectifiers exhibit at amp-level pulse currents, is assumed so the
margin below is not overstated. With $V_{\mathrm{BUS,max}} = \SI{13}{\volt}$
(the input window of \cref{sec:hv-converter}):
\begin{align*}
  V_{\mathrm{cl}}^{\max} = (1-m)\times\SI{100}{\volt} - V_{\mathrm{BUS,max}}
    - V_{F(D202)} = 80 - 13 - 1.5 = \SI{65.5}{\volt}.
\end{align*}
That is $3.4\times$ the reflected voltage, clear of the $2\times$ floor with
room to spare, so the ceiling is the binding constraint. In the energy-balance
equation above, the ratio $V_{\mathrm{cl}}/(V_{\mathrm{cl}} - V_{\mathrm{refl}})$
shrinks toward $1$ as $V_{\mathrm{cl}}$ grows, so a higher clamp voltage
approaches the bare leakage power as an asymptote, while a lower one drives
dissipation up sharply as $V_{\mathrm{cl}}$ nears $V_{\mathrm{refl}}$: raising
$V_{\mathrm{cl}}$ trades switch margin for lower loss. Since absorbing the spike
is the only goal that outranks minimizing loss, and the ceiling already clears
the effectiveness floor, the target is set at the ceiling:
$V_{\mathrm{cl}} = \SI{65.5}{\volt}$.

\subsubsection{R212}

Solving the energy-balance equation for R212 at the target, with the
worst-case-corner clamp power:
\begin{align*}
  R_{212} = \frac{V_{\mathrm{cl}}(V_{\mathrm{cl}} - V_{\mathrm{refl}})}
    {E_{\mathrm{lk}} f_{\mathrm{sw}}}
    = \frac{65.5 \times 46.25}{\SI{94.9}{\milli\watt}} \approx \SI{31.9}{\kilo\ohm}.
\end{align*}
Rounding down to the standard value $R212 = \SI{30}{\kilo\ohm}$ (E24) preserves
margin rather than eroding it; re-solving the same equation for the resulting
clamp voltage at each of the two operating points,
\begin{align*}
  V_{\mathrm{cl}}^2 - V_{\mathrm{refl}} V_{\mathrm{cl}}
    - E_{\mathrm{lk}} f_{\mathrm{sw}} R_{212} = 0
  \;\Longrightarrow\;
  V_{\mathrm{cl}}^{\mathrm{lim}} = \SI{63.8}{\volt}, \qquad
  V_{\mathrm{cl}}^{\mathrm{dm}} = \SI{50.4}{\volt}
\end{align*}
(sustained current-limit corner and normal design-max operation
respectively). At the corner, switch stress is
$V_{DS,\mathrm{pk}} = 13 + 63.8 + 1.5 = \SI{78.3}{\volt}$ against the
\SI{100}{\volt} rating: $21.7\,\%$ margin, meeting the target (the
conservative rounding direction gives slightly more than the $20\,\%$
target). In normal operation the clamp rests at \SI{50.4}{\volt},
$2.6\times$ the reflected voltage, still above the $2\times$ effectiveness
floor, dissipating $V_{\mathrm{cl}}^2/R_{212} \approx \SI{84.7}{\milli\watt}$:
the figure carried in the loss budget (\cref{sec:hv-op-losses}). Under a
sustained overload at the corner, dissipation rises to
$63.8^2/\SI{30}{\kilo\ohm} \approx \SI{136}{\milli\watt}$; since that
condition can persist, R212's power rating must cover it under standard
$50\,\%$ power-derating practice ($\ge\SI{0.27}{\watt}$), with at least the
corner clamp voltage under the same $20\,\%$ voltage-derating logic adopted
above ($\ge\SI{80}{\volt}$).

\subsubsection{C209}

C209's value is bounded by a self-consistency requirement: both the
energy-balance equation and the switch-margin check above treat
$V_{\mathrm{cl}}$ as a single fixed number. If C209 lets the clamp voltage
ripple significantly, the drain's actual peak stress each cycle exceeds the
$V_{\mathrm{cl}}$ used above by roughly the ripple amplitude, eroding
the margin established above. That margin is thinnest at the worst-case
corner, so the bound is evaluated there. Bounding ripple to no more than
$2\,\%$ of $V_{\mathrm{cl}}$ keeps the error negligible without demanding an
oversized capacitor.

The charge delivered to the clamp each cycle follows from the multiplier
relation above ($E_{\mathrm{cl}} = V_{\mathrm{cl}} Q_{\mathrm{cl}}$):
\begin{align*}
  Q_{\mathrm{cl}} = \frac{E_{\mathrm{lk}}}{V_{\mathrm{cl}} - V_{\mathrm{refl}}}
    = \frac{\SI{0.635}{\micro\joule}}{44.55} \approx \SI{14.3}{\nano\coulomb}.
\end{align*}
At a $2\,\%$ ripple target ($\Delta V \le \SI{1.28}{\volt}$ at
$V_{\mathrm{cl}}^{\mathrm{lim}} = \SI{63.8}{\volt}$):
\begin{align*}
  C_{209}^{\min} = \frac{Q_{\mathrm{cl}}}{\Delta V}
    = \frac{\SI{14.3}{\nano\coulomb}}{\SI{1.28}{\volt}} \approx \SI{11.2}{\nano\farad}.
\end{align*}
Rounding up to the standard value $C209 = \SI{12}{\nano\farad}$ (E12) gives
actual ripple $Q_{\mathrm{cl}}/C_{209} \approx \SI{1.19}{\volt}$ ($1.9\,\%$),
and a discharge time constant
$\tau = R_{212} C_{209} \approx \SI{360}{\micro\second}$, about $54$ switching
periods: the clamp settles to a quiet, near-DC node, which is what the
self-consistency assumption above requires. C209 must be rated for
at least the corner clamp voltage under the same derating logic:
$\ge\SI{80}{\volt}$, a $\ge\SI{100}{\volt}$-class part.

\subsubsection{D202 requirements}

D202's requirements follow directly from the numbers above, independent of any
particular part choice, and are left to the diode's actual selection rather
than specified here:
\begin{itemize}[nosep]
  \item \textbf{Reverse voltage.} It must block $V_{\mathrm{BUS,max}} +
    V_{\mathrm{cl}}^{\mathrm{lim}} = 13 + 63.8 = \SI{76.8}{\volt}$ during the
    on-time; at the same $20\,\%$ voltage-derating standard used throughout
    this section, that requires a rated reverse voltage of at least
    \SI{96}{\volt}, i.e.\ a $\ge\SI{100}{\volt}$-class part.
  \item \textbf{Forward current.} While conducting, D202 carries the leakage
    current, decaying linearly from the worst-case \SI{2.91}{\ampere} peak to
    zero over $t_1 = L_{\mathrm{lk}} I_{\mathrm{pk}}/(V_{\mathrm{cl}} -
    V_{\mathrm{refl}}) \approx \SI{9.8}{\nano\second}$: a brief, low-charge
    pulse (\SI{14.3}{\nano\coulomb}, $\approx\SI{2.1}{\milli\ampere}$ average
    once spread over a switching period), far short of the pulse widths
    surge or repetitive-peak current ratings are normally specified against.
    Any rectifier meeting the voltage requirement above satisfies this
    without a separate derating step.
  \item \textbf{Reverse recovery.} D202 conducts at the start of each
    off-interval and must be blocking again before the next turn-on applies
    the full reverse voltage above. The available window is the off-interval,
    which never falls below $T - t_{\mathrm{on}}^{\max} \approx
    \SI{4.0}{\micro\second}$ (\cref{sec:hv-dcm}). A fast
    ($\le\SI{500}{\nano\second}$) or ultrafast ($\le\SI{75}{\nano\second}$)
    recovery-class rectifier clears this by one to three orders of magnitude;
    a standard-recovery (microsecond-class) part is comparable to the window
    itself and is excluded.
\end{itemize}

\subsection{Switch (Q201) stress and losses}\label{sec:hv-switch}

Drain stress is set by the clamp, not the rating-free ring. The binding case
is the sustained current-limit corner the clamp is sized at
(\cref{sec:hv-clamp}):
\begin{align*}
  V_{DS,\mathrm{pk}} &= V_{\mathrm{BUS,max}} + V_{\mathrm{cl}}^{\mathrm{lim}}
    + V_{F(D202)} = 13 + 63.8 + 1.5 = \SI{78.3}{\volt}
\end{align*}
(clamp voltages and the assumed D202 forward drop from \cref{sec:hv-clamp}),
a $21.7\,\%$ margin against the IRL540N's \SI{100}{\volt} rating, meeting by
construction the $20\,\%$ derating target the clamp was sized to. In normal
design-max operation the clamp rests lower and the drain peaks at
$13 + 50.4 + 1.5 \approx \SI{65}{\volt}$ ($35\,\%$ margin). Both cases are
load- but not line-dependent (the current limit and the DCM peak current are
each line-independent), and the
part is avalanche-rated besides. Peak current \SIrange{2.2}{2.9}{\ampere} against
\SI{36}{\ampere} leaves more than an order of magnitude of margin. The
\SI{6.85}{\volt} VCC gate rail fully enhances a
logic-level gate specified at \SI{5}{\volt}; $V_{GS}$ rating ($\pm\SI{16}{\volt}$)
is untouched.

Total switch dissipation at design-max, at the typical turn-off overlap
($t_{\mathrm{ovl}}^{\mathrm{typ}}=\SI{36}{\nano\second}$, \cref{sec:hv-op-losses}):
conduction \SI{33}{\milli\watt} + turn-off \SI{161}{\milli\watt} + $C_{oss}$ few
\si{\milli\watt} $\approx \SI{0.19}{\watt}$, a rise of $\approx\SI{12}{\kelvin}$
on a free-standing vertical TO-220 at $\theta_{JA} \approx
\SI{62}{\kelvin\per\watt}$. Because this check bears on thermal survival rather
than typical operation, it is repeated at the guaranteed-worst-case turn-off
overlap ($t_{\mathrm{ovl}}^{\max}=\SI{54}{\nano\second}$): conduction rises
slightly with the higher commanded peak current to \SI{34}{\milli\watt},
turn-off to \SI{248}{\milli\watt}, for a total $\approx\SI{0.28}{\watt}$ and a
rise of $\approx\SI{17}{\kelvin}$: thermally unremarkable either way.

\textbf{Turn-off overlap remains the single largest loss in the converter}
despite the speedup network below, and is set by the gate-drive resistance
discharging the switch's gate at the $\approx\SI{3}{\volt}$ Miller plateau
sourced in \cref{sec:hv-op-losses}, against a $Q_{GD}$ of
\SIrange{25}{38}{\nano\coulomb} (typical to guaranteed maximum). $R211 =
\SI{10}{\ohm}$ alone (declared in \cref{sec:hv-op-inputs}) would leave this
term at \SIrange{75}{114}{\nano\second}; D203 (SB240S-E3/54) in series with
R214 ($\SI{3.3}{\ohm}$) bypasses $R211$ for the turn-off direction only,
cutting the effective discharge resistance from
$R211+R_{\mathrm{int}}\approx\SI{11.5}{\ohm}$ to
$R214+R_{\mathrm{int}}\approx\SI{4.8}{\ohm}$ and turn-off overlap to the
\SIrange{36}{54}{\nano\second} used throughout this section, at the cost of
two small through-hole parts. $R211$ itself is retained unchanged, governing
turn-on only, since D203 is reverse-biased in that direction.

\subsection{Output rectifier (D201)}\label{sec:hv-rect}

Reverse stress occurs during the on-time:
\begin{align*}
  V_R &= V_{\mathrm{out}} + n V_{\mathrm{BUS,max}}
       = 191.5 + 10 \times 13 = \SI{321.5}{\volt}
\end{align*}
at the design-max envelope (\cref{sec:hv-achieved-range}; a builder who follows
the hardware guide's instruction never tunes past $V_{\mathrm{max}}$, and this
rating assumes that instruction is followed, per \cref{sec:hv-divider-split}),
plus secondary-side ring, under \SI{345}{\volt} against the UF4005's
\SI{600}{\volt}: margin $\ge 42\,\%$.
Forward stress: $I_{F,\mathrm{avg}} = \SI{16}{\milli\ampere}$ (\cref{sec:hv-budget})
and $I_{F,\mathrm{pk}} = I_{\mathrm{pk}}/n = \SI{0.22}{\ampere}$ against a
\SI{1}{\ampere} average rating. Conduction loss $\approx V_F I_{\mathrm{out}}
= \SI{16}{\milli\watt}$. The $\approx\SI{75}{\nano\second}$ recovery is immaterial:
in DCM the diode current reaches zero, and the junction sweeps out, during the idle
interval, so the switch never hard-commutates it. The generic-ultrafast class
fits this position: a Schottky is unavailable at this voltage and
unnecessary at this current.

\subsection{Input and output capacitance}\label{sec:hv-caps}

\subsubsection{Input}

Roles, per standard flyback practice: C202 (\SI{100}{\micro\farad}, radial
polarized, specified as a KEMET A759-class polymer part or equivalent) is the
bulk reservoir for the pulsed primary current; C203 (\SI{4.7}{\micro\farad}
ceramic) closes the high-frequency primary loop; C211 serves the BIAS pin
(\cref{sec:hv-house-bias}). The primary draws triangular pulses of RMS
\SI{0.77}{\ampere} (\cref{sec:hv-op-converge}) against a \SI{0.41}{\ampere} DC
average, leaving $\sqrt{0.77^2 - 0.41^2} =
\SI{0.65}{\ampere}$ RMS of ripple in the capacitor bank. A polymer part absorbs
this trivially (multi-ampere ripple ratings at milliohm ESR); \textbf{a
general-purpose aluminum electrolytic would not: its \SI{150}{\kilo\hertz}
ripple rating (typically \SIrange{0.3}{0.5}{\ampere} for a small
\SI{100}{\micro\farad} can) is marginal even with the ceramic sharing current,
so the polymer family is a requirement here, not a preference.} Bus ripple:
\begin{align*}
  \Delta V \approx
  \frac{(I_{\mathrm{pk}}/2 - I_{\mathrm{in}})\,t_{\mathrm{on}}}{C_{\mathrm{in}}}
  + I_{\mathrm{pk}}\,\mathrm{ESR}
  \approx \frac{\SI{1.7}{\micro\coulomb}}{\SI{105}{\micro\farad}} + 2.16\times0.03
  \approx \SI{81}{\milli\volt}\ \text{pk--pk},
\end{align*}
unobjectionable on a USB-PD input.

\subsubsection{Output}

$C_{\mathrm{out}} = C204\,(\SI{4.7}{\micro\farad}$, radial polarized, polymer
aluminum, A759-class$) + C205\,(\SI{100}{\nano\farad}\ \text{ECQ-E film})$.
Requirement check: the load is constant-current tubes behind large ballasts,
so the rail needs neither hold-up nor transient reservoir: only
switching-ripple control. Capacitive ripple per cycle:
\begin{align*}
  \Delta V_{\mathrm{cap}} &=
  \frac{I_{\mathrm{out}}\,(T - t_{\mathrm{dem}})}{C_{\mathrm{out}}}
  = \frac{15.9\,\si{\milli\ampere} \times 5.6\,\si{\micro\second}}
         {\SI{4.8}{\micro\farad}}
  = \SI{18}{\milli\volt},
\end{align*}
exceeded by the ESR step $I_{s,\mathrm{pk}}\times\mathrm{ESR} \approx 0.22 \times
0.5 \approx \SI{108}{\milli\volt}$ pk--pk ($0.06\,\%$ of the rail) at C204's
$\approx\SI{0.5}{\ohm}$ ESR, with the film part shunting the fast edges.
Through an \SI{10}{\kilo\ohm} ballast (\cref{sec:hv-load-digit}) this modulates
tube current by $\sim$\SI{11}{\micro\ampere} at \SI{150}{\kilo\hertz},
optically invisible. The small capacitance is sufficient, and
beneficial: it keeps the stored energy at \SI{69}{\milli\joule},
the start-up time at \SI{22}{\milli\second} (\cref{sec:hv-ss}), and the
bleed-down inside seconds (\cref{sec:hv-bleeder}).

\textbf{C204's voltage rating must be specified deliberately.} The design-max
envelope is \SI{191.5}{\volt} (\cref{sec:hv-achieved-range}; per
\cref{sec:hv-divider-split}, this design's component ratings assume a builder
never tunes past $V_{\mathrm{max}}$, not the trimmer's full mechanical reach).
The A759 series is offered at a fixed ladder of standard voltage ratings; its
\SI{160}{\volt} step falls short of the envelope, so the \SI{250}{\volt} step
is the one specified, KEMET A759KS475M2EAAE496 (an $8\times12$\,mm case,
ESR \SI{496}{\milli\ohm} at \SI{100}{\kilo\hertz}/\SI{20}{\celsius},
\ds{KEM\_A4072\_A759.pdf}{9}), keeping $\ge$23\,\% headroom at full trim. C205's
ECQ-E film series is \SI{250}{\volt} by default.

\subsection{Bleeder (R202) and minimum load}\label{sec:hv-bleeder}

R202 serves two requirements: it must discharge $C_{\mathrm{out}}$ to a safe
voltage within a bounded time after shutdown, and it must keep the converter
loaded enough to avoid pulse-skipping at light load.

\subsubsection{Discharge}\label{sec:hv-bleeder-discharge}

Stored energy is modest, $\tfrac{1}{2} C_{\mathrm{out}} V^2 =
\tfrac{1}{2}\times\SI{4.8}{\micro\farad}\times 170^2 = \SI{69}{\milli\joule}$
(\cref{sec:hv-caps}), but the node must still bleed down after shutdown. The
tubes do most of the work themselves: holding the rail near their maintaining
voltages while conducting collapses it to $\approx\SI{148}{\volt}$ (digit
extinction) in $\sim$\SI{10}{\milli\second} and to $\approx\SI{92}{\volt}$
(colon extinction) in $\sim$\SI{0.2}{\second}. Below that only the resistive
path, $R202 \parallel R_{\mathrm{div}}$, remains.

IEC 62368-1 classifies $\le\SI{60}{\volt}\,\mathrm{dc}$ as ES1, the
energy-source class safe for an ordinary person to touch, and requires a
capacitor's stored voltage to decay to that limit within \SI{2}{\second} of
disconnection. Targeting \SI{1.8}{\second}, a \SI{0.2}{\second} margin under
that limit, leaves the resistive decay from the \SI{92}{\volt}
colon-extinction point \SI{1.6}{\second} to reach \SI{60}{\volt}:
\begin{align*}
  \tau_{\mathrm{target}} = \frac{\SI{1.6}{\second}}{\ln(92/60)} \approx
  \SI{3.74}{\second}, \qquad
  R_{\mathrm{total,target}} = \frac{\tau_{\mathrm{target}}}{C_{\mathrm{out}}}
  \approx \SI{780}{\kilo\ohm}.
\end{align*}
Against the feedback divider ($R_{\mathrm{div}} \approx \SI{1.70}{\mega\ohm}$,
\cref{sec:hv-divider}), $R202 \parallel R_{\mathrm{div}} =
\SI{780}{\kilo\ohm}$ requires $R202 \approx \SI{1.44}{\mega\ohm}$; the nearest
standard value, $R202 = \SI{1.5}{\mega\ohm}$, gives:
\begin{align*}
  R_{202} \parallel R_{\mathrm{div}} &= 1.5\,\si{\mega\ohm} \parallel
    1.70\,\si{\mega\ohm} = \SI{797}{\kilo\ohm}, \\
  \tau &= \SI{797}{\kilo\ohm} \times \SI{4.8}{\micro\farad} =
    \SI{3.82}{\second}, \qquad
  t_{92\rightarrow 60\,\mathrm{V}} = \tau \ln\frac{92}{60} =
    \SI{1.63}{\second}.
\end{align*}
Total elapsed time from shutdown to \SI{60}{\volt} is
$0.2 + 1.63 \approx \SI{1.83}{\second}$, an \SI{8}{\percent} margin under IEC
62368-1's \SI{2}{\second} window. Dissipation, $170^2/\SI{1.5}{\mega\ohm} =
\SI{19}{\milli\watt}$ at nominal and \SI{24}{\milli\watt} at the design-max
envelope, and \SI{170}{\volt} standing voltage are both well inside the
DIN0207 element's ratings.

\subsubsection{Minimum load}\label{sec:hv-bleeder-minload}

The controller cannot deliver less than one minimum-width pulse per cycle. At
\SI{13}{\volt} input and the $\approx\SI{165}{\nano\second}$ minimum on-time:
\begin{align*}
  I_{\mathrm{pk}}^{\min} &= \frac{V_{\mathrm{BUS}} t_{\mathrm{on,min}}}{L_p}
    = \frac{13 \times 165\,\si{\nano\second}}{\SI{10}{\micro\henry}}
    = \SI{0.21}{\ampere},\\
  P_{\min} &= \tfrac{1}{2} L_p (I_{\mathrm{pk}}^{\min})^2 f_{\mathrm{sw}}\,\eta
    \approx \tfrac{1}{2}\times\SI{10}{\micro\henry}\times 0.046 \times
      149.4\,\si{\kilo\hertz} \times 0.872
    \approx \SI{30}{\milli\watt}.
\end{align*}
Below this load the output would creep upward, or the controller would skip
pulses. The
fixed preload, bleeder $170^2/\SI{1.5}{\mega\ohm} = \SI{19}{\milli\watt}$ plus
divider \SI{17}{\milli\watt} (\cref{sec:hv-divider}), totals
\SI{36}{\milli\watt}, a $1.2\times$ margin over $P_{\min}$. The rail therefore
stays regulated even before the tubes strike.

\subsection{Loop compensation}\label{sec:hv-comp}

\subsubsection{Plant}

A peak-current-mode DCM flyback is, to first order, a controlled current source
into $C_{\mathrm{out}} \parallel R_L$. At the nominal point $R_L =
V_{\mathrm{out}}/I_{\mathrm{out}} = 170/\SI{11.10}{\milli\ampere} =
\SI{15.3}{\kilo\ohm}$ (\cref{sec:hv-budget}) and $C_{\mathrm{out}} = C204 + C205 =
\SI{4.8}{\micro\farad}$ (\cref{sec:hv-caps}).

Modulator gain: the controller's PWM comparator sees COMP through its internal
attenuation $G_{\mathrm{COMP}} = 0.142$ and compares it against the sensed current
plus the fixed internal slope ramp of slope $S_e = \SI{40}{\milli\volt}\times
f_{\mathrm{sw}} = \SI{5975}{\volt\per\second}$ (\ds{lm5155.pdf}{20}). Against the
sensed on-slope $S_n = R_S V_{\mathrm{BUS}}/L_p = 0.039\times9/\SI{10}{\micro\henry}
= \SI{35100}{\volt\per\second}$ (\cref{sec:hv-cs}):
\begin{align*}
  \frac{\partial I_{\mathrm{pk}}}{\partial v_c}
    &= \frac{G_{\mathrm{COMP}}}{R_S\,(1 + S_e/S_n)}
     = \frac{0.142}{0.039 \times 1.17}
     = \SI{3.11}{\ampere\per\volt}.
\end{align*}
Since $I_{\mathrm{out}} = \tfrac{1}{2} L_p I_{\mathrm{pk}}^2 f_{\mathrm{sw}}
\eta / V_{\mathrm{out}}$, the plant transconductance and its output resistance
follow:
\begin{align*}
  \frac{\partial I_{\mathrm{out}}}{\partial I_{\mathrm{pk}}}
    &= \frac{2 I_{\mathrm{out}}}{I_{\mathrm{pk}}}
     = \frac{2 \times 11.10\,\si{\milli\ampere}}{1.73}
     = 12.8\,\si{\milli\ampere\per\ampere},\\
  g_{ps} &= 12.8\,\si{\milli\ampere\per\ampere} \times \SI{3.11}{\ampere\per\volt}
          = \SI{39.8}{\milli\siemens} \text{ (per volt of COMP)},
\end{align*}
and because $I_{\mathrm{out}} \propto 1/V_{\mathrm{out}}$ at fixed peak current,
the converter presents its own output resistance equal to $R_L$, so the loaded
plant sees $R_L/2$ and one dominant pole:
\begin{align*}
  G_0 &= g_{ps}\,\frac{R_L}{2} = 0.0398 \times 7650 = 304\ (\SI{49.7}{\decibel}),
  &
  f_p &= \frac{2}{2\pi R_L C_{\mathrm{out}}}
       = \frac{2}{2\pi \times 15.3\,\si{\kilo\ohm} \times \SI{4.8}{\micro\farad}}
       = \SI{4.3}{\hertz}.
\end{align*}
The DCM right-half-plane zero and the output capacitor's ESR zero
($\approx\SI{67}{\kilo\hertz}$ at C204's \SI{0.5}{\ohm}) both lie far above the
crossover derived below and are neglected.

\subsubsection{Compensator and loop}

The target crossover $f_c$ is bounded on both sides: it must sit well above the
plant pole $f_p = \SI{4.3}{\hertz}$ (\cref{sec:hv-comp}) for the loop to have any
useful bandwidth and gain margin, and well below $f_{\mathrm{sw}}/10$ (standard
peak-current-mode practice, avoiding interaction with switching artifacts):
here $\approx\SI{15}{\kilo\hertz}$. Because the load is quasi-static (no
multiplexing, each tube has a dedicated driver, so digit changes move
milliamps at minutes cadence) and the input rail is pre-regulated USB-PD, nothing
requires pushing $f_c$ toward that upper bound; a target in the low hundreds of
hertz, some fortyfold above $f_p$ and no more bandwidth than the load asks for,
is adopted. A standard Type-II placement follows: the zero near $0.7$--$0.8\,f_c$
(textbook boost of phase at crossover) and the high-frequency pole at least
$10\times$ above $f_c$ (attenuates switching ripple on COMP at negligible cost to
phase there).

The compensator's mid-band gain, set by $g_m R_{210}$ with the
\SI{2}{\milli\siemens} transconductance error amplifier (\ds{lm5155.pdf}{7}),
combines with the plant and divider gains established above to fix where the
loop crosses 0\,dB; the $R_{210}C_{207}$ and $C_{207}/C_{208}$ ratios fix
the zero and high-frequency pole relative to that crossing. Solving for standard
E-series values that realize the target above gives $R210 = \SI{10}{\kilo\ohm}$
in series with $C207 = \SI{100}{\nano\farad}$ on COMP, shunted by
$C208 = \SI{220}{\pico\farad}$:
\begin{align*}
  f_z &= \frac{1}{2\pi R_{210} C_{207}} = \SI{159}{\hertz},
  &
  f_{hp} &= \frac{1}{2\pi R_{210}\,\frac{C_{207}C_{208}}{C_{207}+C_{208}}}
          = \SI{72.5}{\kilo\hertz},
\end{align*}
with integrator behavior below $f_z$ (the amplifier's
$g_m R_O = 2\,\si{\milli\siemens} \times 10\,\si{\mega\ohm} = \SI{86}{\decibel}$
DC gain, \ds{lm5155.pdf}{21}, makes static regulation error negligible). The divider contributes
$H = V_{\mathrm{REF}}/V_{\mathrm{out}} = 1/170$.

Solving $|T(f)| = 1$ for the product of divider, compensator, and plant
(numerically, with all three break frequencies in place) confirms the target:
\begin{align*}
  f_c &\approx \SI{200}{\hertz} \approx \frac{f_{\mathrm{sw}}}{748},\\
  \varphi_m &= 180^\circ - \arctan\frac{f_c}{f_p} - 90^\circ
    + \arctan\frac{f_c}{f_z} - \arctan\frac{f_c}{f_{hp}}
    = 180 - 88.8 - 90 + 51.4 - 0.2 \approx 53^\circ.
\end{align*}
The zero lands at $0.80 f_c$, inside the targeted $0.7$--$0.8\,f_c$ band. The
high-frequency pole is $363\times$ above crossover, far past the
$10\times$ target. Gain
margin is effectively unbounded (the
phase never approaches $-180^\circ$ until far past $f_{hp}$, where loop gain is
tens of dB down). The
modulator constants ($G_{\mathrm{COMP}}$, $S_e$, $g_m$) are datasheet typicals
without tolerance bands; a bench transient or Bode check should verify them.

\subsection{Soft start}\label{sec:hv-ss}

The datasheet's soft-start formulas apply only to boost and SEPIC topologies;
the boost formula in particular assumes an input-to-output pass-through path
that a flyback does not have, so neither formula applies to this design. From the pin's fundamental behavior
(\cref{sec:lm5155}): C206 is charged by $I_{SS} = \SI{10}{\micro\ampere}$, and
the error amplifier regulates FB to the lower of $V_{SS}$ and
$V_{\mathrm{REF}}$, giving a reference-ramp time
$t_{SS} = C_{206} V_{\mathrm{REF}} / I_{SS}$.

Whether the output actually tracks that ramp depends on whether the converter
can deliver enough current to keep up. Running flat out at its own current
limit, the converter can charge $C_{\mathrm{out}}$ from \SI{0}{\volt} to
$V_{\mathrm{out}}$ (the tubes draw nothing until strike, so no load current
competes for this) in
\begin{align*}
  t_{\mathrm{rise}} &\approx
  \frac{\tfrac{1}{2} C_{\mathrm{out}} V_{\mathrm{out}}^2}
       {\tfrac{1}{2} L_p I_{\mathrm{lim}}^2 f_{\mathrm{sw}}\,\eta}
  = \frac{\SI{69}{\milli\joule}}{\SI{4.3}{\watt}}
  \approx \SI{16.2}{\milli\second}.
\end{align*}
$C_{206}$ must be large enough that $t_{SS}$ exceeds $t_{\mathrm{rise}}$;
otherwise the output falls behind the commanded ramp, the error amplifier
saturates into the current limit. Setting $t_{SS} = t_{\mathrm{rise}}$ gives the
minimum:
\begin{align*}
  C_{206}^{\min} &= \frac{t_{\mathrm{rise}} I_{SS}}{V_{\mathrm{REF}}}
    = \frac{\SI{16.2}{\milli\second} \times \SI{10}{\micro\ampere}}{\SI{1.00}{\volt}}
    \approx \SI{162}{\nano\farad}.
\end{align*}
Rounding up to a standard value, $C206 = \SI{220}{\nano\farad}$ is specified,
giving $t_{SS} = \SI{220}{\nano\farad} \times \SI{1.00}{\volt} /
\SI{10}{\micro\ampere} = \SI{22.0}{\milli\second}$ nominal. $C_{206}$'s own
tolerance ($\pm10\,\%$, typical for this class of ceramic) stacks with $I_{SS}$
and $V_{\mathrm{REF}}$'s datasheet-specified ranges
(\SIrange{9}{11}{\micro\ampere} and \SIrange{0.99}{1.01}{\volt} respectively,
\ds{lm5155.pdf}{7}); worst-case-additive:
\begin{align*}
  t_{SS}^{\min} &= \frac{\SI{220}{\nano\farad}\times0.9 \times \SI{0.99}{\volt}}
    {\SI{11}{\micro\ampere}} \approx \SI{17.8}{\milli\second},
\end{align*}
still \SI{1.6}{\milli\second} ($10\,\%$) above $t_{\mathrm{rise}}$. The full
range is \SIrange{17.8}{27.2}{\milli\second}.

Soft start is not strictly required for correct operation with the LM5155 as
specified, which has no hiccup overload protection to trip regardless of how
fast the rail rises; that protection exists in the LM51551 sibling
(\ds{lm5155.pdf}{22}), where a fast, uncontrolled ramp would trip its 64-cycle
fault counter before the rail arrived, making a deliberately sized $C_{206}$
mandatory if that part were used.
