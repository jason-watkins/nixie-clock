\section{5~V and 3.3~V converters: driving component characteristics}
\label{sec:lv-components}

The two low-voltage supplies use different converter types. A TPS629203
synchronous buck converter supplies 5~V to the four K155ID1 drivers. Its input
is always higher than its output. A TPS63070 four-switch buck-boost converter
supplies 3.3~V to the MCU. Its input can be above or below 3.3~V
(\cref{sec:3v3-diodeor}). The following characteristics support both converter
designs.

\subsection{TPS629203 synchronous buck converter}
\label{sec:tps629203}

Source: \texttt{tps629203.pdf}, Texas Instruments SLVSGE2, 2022-03. The device
is a synchronous buck converter with internal compensation. DCS-Control changes
between pulse-width modulation and power-save operation. The device needs no
external bootstrap capacitor. A resistor at FB/VSET selects an external divider
or one of 18 preset output voltages. A resistor at MODE/S-CONF selects feedback,
frequency, output-discharge, and modulation options.

\paragraph{Output-voltage tolerance.} The internal divider gives a
$\pm1\,\%$ output tolerance across the junction-temperature range. With an
external divider, the feedback-reference tolerance and divider-ratio tolerance
both affect the output. Therefore, \cref{sec:5v-vset} uses the internal divider.

\paragraph{Configuration sampling.} The device reads MODE/S-CONF and VSET once
during start-up. It does not read them during operation. Resistor configuration
also disables dynamic mode changes. Both resistors must be E96 $1\,\%$ parts.
Their temperature coefficient must be no more than
$\pm200$~ppm/\si{\celsius}.

\paragraph{Efficiency-enhancement frequency.} The device changes switching
frequency with conversion ratio. This action keeps inductor ripple approximately
constant. Therefore, \cref{sec:5v-op} calculates frequency across the input
range.

\paragraph{Ripple-current limit.} Inductor ripple must not exceed
\SI{1.6}{\ampere}. Above this value, the low-side negative current limit can
operate continuously at no load. This value sets the minimum inductance for a
given input voltage.

\paragraph{Input range.} The device takes its internal supply from the higher
of VIN and VOUT. It needs \SI{3.0}{\volt} to start. After start-up, it operates
to \SI{2.0}{\volt} input when VOUT is at least \SI{3.0}{\volt}. Therefore, an
input source must supply at least \SI{3.0}{\volt} at start-up.
\Cref{sec:3v3-diodeor} applies this requirement.

\paragraph{Output-current condition.} The \SI{2}{\ampere} value applies only in
buck operation when VIN or VOUT is at least \SI{4.5}{\volt}. The datasheet does
not give a guaranteed value outside these conditions. It gives only application
curves.

\paragraph{Power Save Mode.} Below approximately
\SI{650}{\milli\ampere} of inductor current, the converter skips cycles. The
output is then approximately \SI{1}{\percent} above nominal. Feedback tolerance
changes from $\pm1\,\%$ to $+3/-1\,\%$. PS/SYNC selects this mode. A low level
at PS/SYNC disables it.

\paragraph{Adjustable-variant tolerance.} For the adjustable part, the
datasheet specifies $V_{FB}$ tolerance. Divider-ratio tolerance and
\SI{100}{\nano\ampere} feedback leakage also affect the output.
\Cref{sec:3v3-fb,sec:3v3-cout} include both effects.

\paragraph{Package.} The part is available only in a 13-pin VQFN with a
$2.5\times3$~\si{\milli\meter} body. Therefore, this package is a design
requirement.
