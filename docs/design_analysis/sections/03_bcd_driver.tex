\section{BCD decoder/driver characteristics}
\label{sec:bcd-driver}

Each IN-12B digit tube (NX1--NX4, \cref{sec:tubes}) is
paired one-to-one with a K155ID1 BCD decoder/driver, designated
U1--U4 throughout this document, a Soviet-made
functional clone of the Texas Instruments SN74141. Each of the driver's
ten outputs is an
open-collector transistor wired directly to one cathode of its tube;
the selected (lit) output sinks current, pulling that cathode low,
while the other nine sit in a high-impedance off state. There is no
interposing high-voltage buffer transistor between driver and tube in
this design: the driver's own output stage must tolerate whatever
voltage an unselected cathode presents.

\paragraph{Substitution.} No K155ID1 datasheet is on file in
\texttt{docs/datasheets/}. The K155ID1 is treated as electrically
equivalent to the TI SN74141 it clones, and the figures below are
transcribed from that part's datasheet (\texttt{SN74141\_TI.pdf}, Texas Instruments,
originally published 1972, revised 1983) instead. The datasheet itself
splits these figures across two tables, Absolute Maximum Ratings and
Recommended Operating Conditions/Electrical Characteristics; the
following two tables preserve that split, since
\cref{sec:bcd-voltage-risk} depends on which table a given off-state
voltage figure comes from. Rows drawn from the second source table are
tagged \textbf{[ROC]} (Recommended Operating Conditions) or
\textbf{[EC]} (Electrical Characteristics).

\subsection{The off-state voltage question}
\label{sec:bcd-voltage-risk}

The datasheet's Absolute Maximum Ratings table gives no distinct
off-state output voltage limit; it bounds only off-state output
\emph{current} (\SI{2}{\milli\ampere}). The only off-state voltage
figure anywhere in the datasheet is \SI{60}{\volt}, and it is a
\emph{guaranteed operating} point (Recommended Operating Conditions,
and corroborated by the \(V_{O(off)}\) electrical-characteristics row,
which promises no breakdown up to \SI{60}{\volt} under a
\SI{0.5}{\milli\ampere} test load) rather than a stated destructive
limit; the datasheet does not say what happens above it, only that
correct operation is guaranteed up to it. Two separate leakage-current
test points exist below that ceiling (\SI{50}{\micro\ampere} max at
\(V_O=\SI{55}{\volt}\), and \SI{5}{}/\SI{15}{\micro\ampere}
typ/max at \(V_O=\SI{30}{\volt}\) with all ten outputs off) and should
not be mistaken for the guaranteed standoff voltage itself.

This board's anode rail spans \SIrange{164.8}{191.5}{\volt}
(\cref{sec:hv-converter}), and with no buffer transistor between
driver and tube, an unselected cathode is exposed to something on the
order of the tube's maintaining voltage up to the full rail voltage
(\SIrange{145}{191.5}{\volt} by the figures in \cref{sec:tubes}),
2.4--3.2$\times$ the datasheet's guaranteed \SI{60}{\volt} standoff.

Direct cathode drive from a 7441/74141/K155ID1-class open-collector
decoder, run well above its guaranteed off-state rating, is the
standard topology in amateur IN-12/IN-14-class Nixie clocks, with a
long track record of field reliability at rail voltages in this same
range. Two effects plausibly
explain the margin, neither confirmed from a cited source: guaranteed
datasheet minimums are worst-case production-lot figures, and the
actual breakdown point of a given part typically exceeds the guarantee
by a wide margin; and an unselected cathode inside a lit tube floats
within the tube's own glow-discharge field, with no external
low-impedance source driving it, so a simple resistive off-state model
overstates the potential it actually sees. The question stays open
pending a K155ID1-specific datasheet, which might state a higher
verified rating.
