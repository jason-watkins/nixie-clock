\section{BCD decoder/driver characteristics}
\label{sec:bcd-driver}

One K155ID1 BCD decoder/driver controls each IN-12B tube
(\cref{sec:tubes}). U1 to U4 are Soviet functional equivalents of the Texas
Instruments SN74141. Each driver has ten open-collector outputs. Each output
connects directly to one tube cathode. The selected output sinks current and
pulls its cathode low. The other nine outputs are high impedance. The circuit
has no high-voltage buffer between the driver and the tube. Thus, the driver
output must tolerate the voltage on an unselected cathode.

\paragraph{Substitution.} No K155ID1 datasheet is in
\texttt{docs/datasheets/}. This analysis assumes that the K155ID1 is
electrically equivalent to the SN74141 (inferred). The values come from
\texttt{SN74141\_TI.pdf}, published in 1972 and revised in 1983. The source has
separate absolute-maximum and operating-characteristic tables. The following
tables keep this separation. \Cref{sec:bcd-voltage-risk} depends on the source
of each off-state voltage. Tags \textbf{[ROC]} and \textbf{[EC]} identify the
two operating tables.

Pin mapping for the 16-pin DIP: BCD inputs A, B, C, and D are on pins 3, 6, 7,
and 4. \(V_{CC}\) is on pin 5. Ground is on pin 12. Outputs 0 to 9 are on pins
16, 15, 8, 9, 13, 14, 11, 10, 1, and 2. The datasheet does not specify package
thermal resistance, maximum junction temperature, ESD rating, or propagation
delay.

\subsection{Off-state output voltage}
\label{sec:bcd-voltage-risk}

The absolute-maximum table gives no off-state output-voltage limit. It gives
only a \SI{2}{\milli\ampere} off-state output-current limit. The only off-state
voltage is \SI{60}{\volt}. This value is a guaranteed operating condition. The
electrical-characteristics table also guarantees no breakdown at
\SI{60}{\volt} with a \SI{0.5}{\milli\ampere} test load. The datasheet does not
specify operation above \SI{60}{\volt}.

Two leakage-current tests use lower voltages. The maximum leakage is
\SI{50}{\micro\ampere} at \SI{55}{\volt}. The typical and maximum leakage is
\SI{5}{\micro\ampere} and \SI{15}{\micro\ampere} at \SI{30}{\volt}. These test
values are not standoff-voltage limits.

The anode rail spans \SIrange{164.8}{191.5}{\volt}
(\cref{sec:hv-converter}). An unselected cathode can see approximately
\SIrange{145}{191.5}{\volt}. This range is 2.4 to 3.2 times the guaranteed
\SI{60}{\volt} standoff.

Amateur Nixie clocks commonly use direct cathode drive at similar rail voltages
(inferred). This use does not prove compliance with the SN74141 rating. The
actual breakdown voltage can exceed the guaranteed value (inferred). Also, an
unselected cathode floats in the tube discharge field (inferred). A resistive
model can therefore overestimate its voltage. These explanations have no cited
source. The item remains open until a K155ID1 datasheet or a measurement gives
a higher verified rating.
