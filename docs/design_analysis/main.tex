\begin{abstract}
\noindent
This document derives the main electrical characteristics of the Nixie Clock
board. It uses component datasheets and circuit analysis. The analysis applies
at the schematic level. Package data applies only when a part is available in
one package. Each numerical value for a critical component has a datasheet
reference in \texttt{docs/datasheets/}. Other component values use standard
engineering practice. The analysis starts at the Nixie-tube load. It then
derives the 170~V, 5~V, and 3.3~V supplies. The final section derives the
USB-PD input stage.
\end{abstract}
